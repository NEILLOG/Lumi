# 常見問題與錯誤訊息

> 看到錯誤訊息或功能不能用時，查這裡：金鑰無效、無法連線、速率限制、語音、Lumi 無法啟動。

每一項都分成三部分：看到什麼（畫面上的原文）、代表什麼、怎麼處理。對話中的錯誤會顯示在對話下方，附「重試」與「換模型重試」兩個按鈕，對話內容都會保留。

## 怎麼自己檢查狀態？

- 點右上角的齒輪打開設定視窗，「設定首頁」的「待處理」會列出需要處理的事，例如「還沒有設定模型」「AI 連線缺少金鑰」「AI 連線失敗」「AI 連線尚未測試」「語音辨識尚未設定」。沒有問題會寫「目前沒有需要處理的項目」。連線的項目可以直接按「測試連線」或「重新測試」。
- 設定 › AI 連線：選一個連線按「測試連線」。成功顯示「成功 · 可用模型 N 個」，失敗顯示「連線失敗」和原因，原因文字同下面各項。
- 工作台上方模型按鈕的圓點，是這個連線最近一次測試或對話的結果；滑鼠停在按鈕上會寫「已連線」「連線失敗」或「尚未確認」。

## 連線與金鑰

### 「還沒有可用的模型，請先到設定加入連線與模型。」或「未設定模型，點此開啟設定」

- 代表：還沒有新增模型，或預設模型已被刪除。
- 處理：照[開始使用](getting-started.md)新增連線與模型。

### 「金鑰無效或已失效，請重新輸入。」「金鑰無法讀取，請重新輸入。」「連線「…」尚未設定 API 金鑰。」

- 代表：金鑰填錯、被供應商停用，或這台電腦讀不出已存的金鑰。服務要求金鑰卻沒填時，通常也會看到第一句。
- 處理：Lumi 會自動開啟設定視窗並停在金鑰欄位，上方有「金鑰無效，請重新輸入。」之類的提示。貼上新金鑰並按「儲存」，Lumi 會自動重送。如果是剛申請的金鑰，先到供應商後台確認它已啟用。

### 「這個帳號沒有權限使用此模型。」

- 代表：金鑰有效，但這個帳號不能使用你選的模型。
- 處理：換一個模型，或到供應商後台確認帳號的方案與權限。

### 「請輸入完整的網址（http:// 或 https:// 開頭）。」「這是 http 連線，金鑰會以明文在網路上傳送……」

- 代表：Base URL 沒有以 `http://` 或 `https://` 開頭，儲存不了；第二句是警告，表示你填的是沒有加密的 `http://` 網址，而且不是本機或內部網路。
- 處理：照供應商提供的網址填完整。供應商沒有提供 `https://` 時，只建議在本機或內部網路使用 `http://`。

### 「找不到指定的模型，或 Base URL 不正確（通常需要包含 /v1）。」

- 代表：模型 ID 打錯、帳號用不了這個模型，或 Base URL 填錯。Anthropic 連線只會顯示「找不到指定的模型。」測試連線時可能顯示「找不到模型清單（/models）。」，意思相同。
- 處理：到設定 › AI 連線，確認「Base URL」。OpenAI 相容的服務通常要以 `/v1` 結尾。再確認模型的「模型 ID」；服務沒有提供清單時，可以直接手動輸入。

### 「無法連線到 …，請確認 Base URL 與服務是否已啟動。」「無法連線到 Anthropic。」「連線逾時。」

- 代表：Lumi 連不到服務。可能是網址錯、服務沒開（例如本機的 Ollama 沒執行）、網路不通，或公司網路要經過 Proxy。
- 處理：先確認網址與服務有在執行，再確認網路可以上網。在公司網路裡請看[網路與 Proxy](network.md)。

### 後面多了「看起來沒有網路連線。」

- 代表：Lumi 偵測到這台電腦目前沒有可用的網路。
- 處理：檢查 Wi-Fi 或網路線、VPN，連上網路後按「重試」。

### 「與伺服器的連線中斷。」「回應意外中斷。」「伺服器在串流中回報錯誤。」「與 Anthropic 的連線發生錯誤。」「串流資料解析失敗。」

- 代表：回答到一半連線斷了。
- 處理：按「重試」。常常發生的話，檢查網路，或換一個模型。

## 額度與服務

### 「已達到速率限制，請稍後再試。」（可能寫成「約 N 秒後再試」）

- 代表：短時間內送出太多請求，超過服務允許的速度。「約 N 秒」是服務告訴 Lumi 要等的時間。
- 處理：等那段時間後按「重試」。一直發生的話，到供應商後台查看帳號的額度與用量。

### 「服務暫時過載，請稍後再試。」「伺服器發生錯誤，請稍後再試。」「Anthropic 服務發生錯誤，請稍後再試。」

- 代表：問題在服務那一端，不是你的設定。
- 處理：等幾分鐘按「重試」，或按「換模型重試」改用別的模型。

### 「發生未預期的錯誤，請再試一次。」「發生未預期的錯誤。」

- 代表：Lumi 遇到沒有預期到的狀況。
- 處理：按「重試」；仍然發生，請用[下面的方式](#回報問題時可以附什麼)取得記錄檔回報。

### 「伺服器回應了未預期的狀態碼 N。」

- 代表：服務回了 Lumi 不認得的錯誤。
- 處理：先按「重試」；仍然發生，請確認 Base URL 與服務是否正常，並用[下面的方式](#回報問題時可以附什麼)取得記錄檔回報。

## 請求被拒

### 「請求內容不被伺服器接受。這個模型可能不支援工具或圖片……」

- 代表：服務拒絕了這次請求。常見原因是模型不支援工具或圖片，例如某些小型的本機模型。只寫「請求內容不被伺服器接受。」或「請求格式不正確。」時，原因不明。
- 處理：不支援工具時，到設定 › AI 連線，打開該模型，取消勾選「使用工具」再重試。不支援圖片時，把圖片從對話移除再重試。

### 「這則對話太長，整理後仍超過模型能處理的長度。請開新對話繼續。」

- 代表：對話內容超過模型一次能讀的長度。Lumi 會先自動整理前面的內容再重送一次，整理後還是太長才會看到這句。
- 處理：開新對話繼續。也可以到設定 › AI 連線，確認該模型「進階」裡的「上下文上限」符合模型實際的能力；Lumi 依這個數字決定何時自動整理。看到「整理對話失敗，對話內容沒有改變。」時，可以稍後再試，或開新對話。

### 「模型拒絕回答這個請求。」「伺服器因內容過濾拒絕了這個回應。」

- 代表：模型或服務拒絕了這個請求；第二句是服務的內容過濾擋下了回應。
- 處理：換個說法重問，或換一個模型。

## 回應是空的

- 看到：Lumi 跑了一陣子，回應卻完全沒有文字，也沒有錯誤訊息。
- 代表：原因可能有很多種，目前無法一概而論。
- 處理：重新送出同一個問題；回覆下方有「重新產生」時可直接按。仍然是空的，換一個模型，或開新對話再問一次。

## 語音

### 語音輸入按鈕灰掉了

把滑鼠停在灰掉的「語音輸入」按鈕上，會顯示原因：

- 「尚未設定語音服務，請到設定裡的語音頁」「語音服務端點有誤，請到設定裡的語音頁修正」「語音服務尚未設定 Token」：到設定 › 語音填好服務端點與 Token。Lumi 沒有內建語音辨識，要自備可以轉寫語音的 Whisper 服務。
- 「回應中，暫時無法語音輸入」：等回應結束。
- 「已在錄音或轉寫中」「另一個視窗正在語音輸入」：先完成或取消目前的錄音。
- 「上一段錄音還沒處理，請先重試或放棄」：上一段轉寫失敗，錄音還留著，按「重試轉寫」或「放棄」。
- 「小精靈暫時隱藏中，請先顯示小精靈再語音輸入」：在 Windows 右下角通知區域或 macOS 上方選單列的 Lumi 圖示上，選「顯示小精靈」。

### 「沒有收到聲音，請確認麥克風權限」

- 代表：整段錄音幾乎沒有聲音，多半是沒有麥克風權限，或麥克風沒有收音。
- 處理：Windows 打開「設定」，進入「隱私權與安全性」，點「麥克風」，允許桌面應用程式存取麥克風。macOS 打開「系統設定」，進入「隱私權與安全性」，點「麥克風」，允許 Lumi。再確認有接上麥克風，重新錄一次。如果顯示「找不到可用的麥克風。」，請先接上麥克風。只錄不到半秒會顯示「錄音時間太短，已忽略」；錄到了但沒聽出內容會顯示「沒有聽到內容」。

### 「語音轉寫失敗」

- 代表：錄音已送到你設定的語音服務，但轉寫沒有成功；原因會寫在下面，例如「Token 無效，或沒有 WHISPER_API 權限。」「無法連線，請確認網址、網路或 VPN。」「錄音檔太大。」
- 處理：照原因修正後按「重試轉寫」，錄音會保留；不想要了按「放棄」。設定方式見[語音輸入](voice.md)。

## 工具

### 「這個工具在目前模式不能使用。」

- 代表：有些工具只能在工作台使用，例如寫入檔案、操作瀏覽器；你正在用小精靈。
- 處理：切到工作台再做一次。

### 「工具呼叫已達到 10 次上限，先停下來了。」「「…」連續 3 次失敗，先停下來了。」

- 代表：Lumi 為了避免無止境地嘗試，一次回應最多連續進行 10 輪工具呼叫；同一個工具用相同做法連續失敗 3 次也會停下來。已完成的步驟都保留。
- 處理：按「重試」接著做；連續失敗時，先補充說明（例如檔案放在哪裡），再請它做一次。

### 想用的工具沒有出現或不能用

- 在設定 › 工具開啟或關閉工具，從下一則新對話開始才生效。
- 模型若關閉了「使用工具」，對話中不會送出任何工具。
- 看到「這個工具目前無法使用。」代表程式更新後這個工具已經移除；開新對話即可。
- 看到「長期記憶已在設定裡關閉，不能新增、修改或刪除記憶。」，到設定 › 記憶重新開啟長期記憶。

## 執行指令

### 「這段指令被 Lumi 擋下：…」

- 代表：指令用了 Lumi 直接擋下的寫法，例如要求系統管理員權限、編碼過的指令、下載後直接執行、影響整台電腦的操作。這類指令不會詢問你。
- 處理：真的需要的話，請自己在終端機執行。文字裡剛好出現 `sudo` 這類字也可能被誤擋，可以請 Lumi 換個寫法。見[執行指令](commands.md)。

### 「這個工具已經在設定關閉，不能使用。」

- 代表：「執行指令」在 設定 › 工具 被關掉了，已經開著的對話也不能再用。
- 處理：到 設定 › 工具 重新開啟，再開一則新對話。

### 指令一直沒有結束，或卡片寫「逾時」

- 代表：指令超過時間限制（預設 120 秒，最長 10 分鐘），或在等待輸入（例如 `npx` 問要不要安裝、`git` 要求登入）。Lumi 執行的指令拿不到鍵盤輸入。
- 處理：請 Lumi 改用不需要回答的寫法，或延長時間；需要登入或回答問題的指令，請自己在終端機執行。

### 指令的輸出中文變成亂碼

- 代表：有些程式用的文字編碼和 Lumi 預期的不同，常見於 Windows 的舊程式。
- 處理：可以請 Lumi 改用 PowerShell 的指令，或改用另一個 shell（PowerShell 與 cmd）再試一次。

### 「這台電腦不能用 …」「這台電腦不支援執行指令。」

- 代表：Windows 只能用 PowerShell 與 cmd，macOS 只能用 bash。
- 處理：請 Lumi 改用這台電腦能用的 shell。

## 檔案與文件

### 「這份文件有密碼保護，無法讀取。」

- 代表：Word、Excel、PowerPoint 或 PDF 設了開啟密碼，Lumi 讀不了加密的文件。
- 處理：用原本的程式移除密碼並另存新檔，再加入對話。

### 「…是舊版 Office 格式（.doc），無法讀取。」

- 代表：舊格式 .doc、.xls、.ppt 不能讀。
- 處理：在 Office 另存新檔為 .docx、.xlsx 或 .pptx 後再試。

### 「讀取文件逾時，已停止。」

- 代表：文件太大或內容太複雜，讀取超過 60 秒。
- 處理：把文件拆成較小的檔案再加入。

### 「這不是文字檔（可能是二進位檔、圖片或其他編碼）。」

- 代表：用讀取純文字的方式打開了不是純文字的檔案。
- 處理：Word、Excel、PowerPoint、PDF 由「讀取文件」工具讀取；其他格式目前不支援。

## 圖片生成

### 「還沒有設定圖片生成。」

- 代表：還沒有選圖片生成用的連線與模型，或選的連線已被刪除。
- 處理：到設定 › AI 連線，捲到最下面的「圖片生成」選連線與模型，再請 Lumi 產生一次。

### 「圖片生成需要 OpenAI 相容格式的連線，請到設定改選這類連線。」

- 代表：圖片生成選的連線是「Anthropic 原生」格式，圖片生成只支援「OpenAI 相容」。
- 處理：到設定 › AI 連線 › 圖片生成，改選一個「OpenAI 相容」的連線與模型。

### 「尺寸只能是 1024x1024、1536x1024 或 1024x1536。」

- 代表：要求的尺寸不在支援的三種之中。
- 處理：不指定尺寸用預設值，或改用這三種之一。

## 技能

### Lumi 沒有用我的技能

按照下面的順序檢查：

1. **舊對話不會用技能**：在這個版本之前開的對話，看不到技能清單。按「新對話」開一則新的再試。
2. **技能停用或讀不進來**：到 設定 › 技能 看清單。沒有勾選「啟用」的技能不會被用；列上寫「讀不進來：原因」的技能也不會被用。原因是「缺少描述。」時，補上「什麼時候用」即可。
3. **模型關閉了「使用工具」**：這個模型送不出任何工具，技能也不會被讀。到 設定 › AI 連線 打開該模型的「使用工具」。
4. **工具頁關掉了「使用技能」**：到 設定 › 工具 重新勾選，之後新開的對話才會生效。
5. **「什麼時候用」寫得太籠統**：Lumi 是看這一段決定要不要讀技能。改成具體情境，例如「每週五整理本週工作、照公司格式寫週報時使用」，比「寫報告」好。
6. **直接指定**：在輸入框按「技能」，選那個技能再送出，Lumi 一定會讀。

對話裡看到「使用技能 · 名稱」的卡片，代表 Lumi 這次確實讀了那個技能；沒有這張卡片，代表這次沒有讀。

### 匯入技能時出現的訊息

- 「找不到 SKILL.md，這可能不是技能。」：選的資料夾或 zip 裡沒有 `SKILL.md`。確認選的是技能本身的資料夾（裡面直接有 `SKILL.md`），不是它的上一層；zip 也要是壓縮技能資料夾本身。
- 「這裡面有好幾個技能，請一次匯入一個。」：資料夾或 zip 裡有好幾個 `SKILL.md`。把它們分開，一次只選一個。
- 「只能匯入資料夾或 zip 檔。」：選的是其他類型的檔案。請選技能資料夾，或副檔名是 `.zip` 的壓縮檔。
- 「壓縮檔裡有不安全的路徑（絕對路徑），不能匯入。」、「壓縮檔裡有不安全的路徑（跳出資料夾），不能匯入。」、「壓縮檔裡有符號連結，不能匯入。」：為了安全，這種壓縮檔不能匯入。改用原來的技能資料夾重新壓縮，或換一個可信來源的檔案。
- 「技能超過 2 MB，不能匯入。」、「解壓後太大（超過 2 MB），不能匯入。」、「技能裡的檔案超過 50 個，不能匯入。」：超過大小或檔案數的上限。技能的步驟請保持精簡，參考資料不要整包放進來。
- 「讀取失敗，檔案可能已損壞或無法讀取。」：檔案損壞、被其他程式鎖住，或沒有權限。確認檔案能用其他程式打開後再試。

## 外部工具（MCP）連線失敗

[連接外部工具（MCP）](mcp.md)的伺服器連線失敗時，會寫出原因。常見的有：

### 「找不到指令「…」」

- 代表：設定的啟動指令在這台電腦找不到，通常是還沒安裝那個程式。
- 處理：先安裝該程式，並確認指令名稱拼寫正確，再重新連線。

### 「伺服器拒絕驗證，請檢查標頭」

- 代表：伺服器拒絕了你給的驗證資訊。
- 處理：檢查伺服器設定裡的標頭與金鑰是否正確、是否過期。

### 「網路連線失敗」「伺服器提前結束連線」

- 代表：連不到伺服器，或伺服器啟動後很快就結束了。
- 處理：確認網路可以連到伺服器，再參考[連接外部工具（MCP）](mcp.md)的說明。

## Lumi 無法啟動怎麼辦？

啟動失敗時會出現「Lumi 無法啟動」視窗，寫出原因：

- 「資料庫正被其他程序使用中，Lumi 可能已經在執行。請先關閉已開啟的 Lumi（也檢查工作列的圖示）再試。」：照字面關閉已開啟的 Lumi 再重開。
- 「沒有權限讀寫 Lumi 的資料資料夾，請檢查該資料夾的權限後再試。」：照字面檢查資料夾權限。
- 「磁碟空間不足，無法寫入資料庫，請釋放空間後再試。」：釋放空間後重開。
- 「資料庫是較新版本的 Lumi 建立的，這個版本無法開啟，請更新 Lumi 後再試。」：更新 Lumi。
- 「設定檔無法讀取，請確認檔案沒有被其他程式鎖住。」：關掉可能鎖住它的程式再試。
- 「發生未預期的錯誤，Lumi 無法啟動。」：先重開；仍然發生，請回報問題。

另外，對話中若看到「Lumi 的程式檔案不完整，請重新啟動 Lumi；仍然發生請重新下載安裝。」，重新啟動即可，不行就重新下載安裝。

打開設定時，如果最上方出現「設定檔損毀，已改用預設設定。」，代表設定檔壞了，連線與模型等設定都被重設，需要重新新增；原本的檔案會改名（檔名含 `broken`）留在 Lumi 的資料資料夾。如果出現「設定檔是較新版本的 Lumi 建立的……」，代表這個版本比較舊；這次 Lumi 先用預設設定，而且不會儲存任何設定變更，請更新 Lumi。

### 回報問題時可以附什麼？

- 視窗裡的「複製詳細資訊」會複製時間、版本、作業系統與錯誤類型，不含對話內容、金鑰或設定檔內容。
- 記錄檔是檔名像 `lumi-日期.log` 的檔案，位置寫在視窗的「記錄檔資料夾」。Lumi 能開啟時，到設定 › 資料與隱私找「記錄檔」，按「在檔案總管顯示」（macOS 是「在 Finder 顯示」）。Windows 預設在 `%APPDATA%\Lumi\logs`，macOS 在 `~/Library/Application Support/Lumi/logs`。附上前建議先打開看看，確認沒有不想公開的內容。
