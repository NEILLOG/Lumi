# 執行指令

> 讓 Lumi 在你的電腦上執行 PowerShell、cmd 或 bash 指令，例如安裝 npm 套件、查詢電腦狀態。預設關閉，只建議熟悉指令的人開啟。

## 這個功能做什麼？

開啟後，Lumi 在工作台裡可以替你執行一段指令，再根據輸出繼續回答。例如：

- 在專案資料夾裡執行 `npm install`，安裝套件。
- 安裝某個技能需要的套件。
- 查詢電腦的狀態：網路設定、磁碟空間、執行中的程式、`git status`。

可以用的 shell：

- **Windows**：Windows PowerShell（預設）與 cmd。
- **macOS**：bash（`/bin/bash`）。你平常用的是 zsh 也沒關係，PATH 會照你的登入設定帶入，nvm、Homebrew 安裝的程式找得到；但 `.zshrc` 裡的別名不會有。

這個功能只在工作台使用；小精靈裡不能執行指令。

## 怎麼開啟？

1. 到「設定 › 工具」，找到「執行指令」群組。
2. 打開「執行指令」的開關。
3. 會跳出警告，說明這個功能能做到什麼。看完按「我了解，開啟」；按取消就維持關閉。
4. **開新對話**才會用到。之前開的對話不會有這個工具。

要關閉時，把開關關掉即可。關閉後**立即生效**：已經開著的對話也不能再執行指令，Lumi 會收到「這個工具已經在設定關閉，不能使用。」

## 確認卡怎麼看？

每次執行前都會出現「要執行這段指令嗎？」的確認卡，沒有「本次對話都允許」，也不能設成「永遠允許」。卡片上有：

- **Lumi 的說明**：Lumi 自己寫的一句話，說明這段指令要做什麼。**請以下面的指令為準**，說明不一定正確。
- **指令**：完整的指令內容，不會收合。看不懂的指令，請按「拒絕」。
- **執行位置**：指令從哪個資料夾開始執行，見下一節。
- **風險提示**：Lumi 從指令內容看出來的事，例如「會刪除檔案或資料夾」「會安裝套件」「會連上網路」「會變更系統設定」。沒有提示不代表安全。
- **外部內容的警告**：這則對話讀過網頁、外部工具（MCP）的內容時，會多一行「這則對話讀過網頁或外部工具的內容。如果這段指令不是你要求的，請按「拒絕」。」網頁裡可能藏著要 Lumi 執行指令的文字，看到這行請特別確認是不是你要的。

按「允許執行」才會執行；按「拒絕」，Lumi 會收到「被拒絕」，不會換個方式再試。

排程自動執行時，碰到執行指令一定會停下來等你確認，不會在無人看著的時候執行。

## 執行位置

- 你請 Lumi 在某個資料夾執行時，它會指定那個資料夾（必須是你加入這則對話的資料夾）。
- 沒有指定時：這則對話只加入一個資料夾，就在那個資料夾執行；否則在這則對話專屬的暫存資料夾執行。

**這不是沙盒。** 執行位置只是起點，指令可以切換到其他資料夾，能做到你自己在終端機能做的任何事，包括刪除你的檔案、把資料傳到網路上。Lumi 的「只能存取你加入的檔案」規則管不到指令。

## 會被直接擋下的寫法

有些寫法 Lumi 不會詢問，直接回「這段指令被 Lumi 擋下」，並請你自己在終端機執行：

- 要求系統管理員權限，例如 `sudo`、`runas`。
- 指令內容被編碼或動態產生，例如 `-EncodedCommand`、`Invoke-Expression`、`eval`。
- 下載後直接執行，例如 `curl … | bash`。
- 影響整台電腦，例如格式化、關機、刪除登錄檔、改開機設定。
- 整個刪除磁碟根目錄或你的使用者資料夾。
- 改變系統的安全設定，例如執行原則、防毒設定、防火牆。

這只是防手滑，**不是安全防線**：換個寫法就可能擋不住，真正的防線是你每次的確認。文字裡剛好出現 `sudo` 之類的字，也可能被誤擋。

## 執行時的限制

- **不能等待輸入**：指令拿不到鍵盤輸入。要你回答問題的程式（例如 `npx` 問「要不要安裝」）會直接失敗，請 Lumi 改用不需要回答的寫法，或自己在終端機執行。
- **逾時**：預設 120 秒，Lumi 可以視情況延長，最長 10 分鐘。逾時或你按「停止」時，指令和它啟動的程式會一起被結束。
- **輸出太長**：只把開頭與結尾交給 Lumi，避免用量暴增。需要完整內容時，可以請 Lumi 把輸出寫進檔案再讀。
- **執行中**：卡片上會顯示最新一行輸出。
- **代理**：npm、git 等程式用它們自己的代理設定，Lumi 的網路設定管不到指令。在代理後面要先設定好，例如 `npm config set proxy`。

## macOS 的權限詢問

指令讀取「文件」「桌面」「下載」等資料夾時，macOS 可能會以 Lumi 的名義詢問要不要允許。這是系統的保護，按「允許」指令才讀得到；按「不允許」指令會失敗。之後可以到 macOS 的「系統設定」，在「隱私權與安全性」的「檔案與資料夾」裡修改。

## 安全

- 只在你知道這段指令在做什麼的時候按「允許執行」。
- 指令的輸出會送到你使用的 AI 供應商，見[資料與隱私](privacy.md)。輸出裡可能有路徑、帳號名稱等資訊。
- 技能請從「設定 › 技能」匯入，不要請 Lumi 用指令把技能放進技能資料夾，見[技能](skills.md)。指令會動到技能資料夾時，確認卡會提醒你。
