# 調整 Lumi 的個性與外觀

> 個性、主動程度、自訂人設、主題色、開機啟動與檢查更新。

## Lumi 的說話個性可以怎麼選？

1. 點右上角的齒輪打開設定視窗，點左邊的「人格與主動性」。
2. 在「說話個性」區塊的「個性」選一種：
   - **溫和友善**（預設）：親切自然，像一位好相處的朋友。
   - **專業精簡**：客觀有條理，直接給結論，省略寒暄。
   - **活潑俏皮**：輕快帶點幽默，偶爾用 emoji；嚴肅的話題會收起玩笑。
   - **冷靜理性**：語氣平穩，著重事實與推理，不確定時明說。
3. 按「儲存」。畫面會寫「已儲存，下一則訊息起生效。」

## 主動程度要怎麼調？

在「主動程度」區塊的「積極度」選單選一段：

- **保守**：只回答被問的事，不主動延伸。
- **適中**（預設）：必要時補充一項建議或提醒。
- **積極**：主動指出問題、提出下一步；需求不清楚時先問。

積極度只影響回答的主動程度，**不會改變工具的權限確認**。要不要讓 Lumi 動手做事，仍然由[工具與權限確認](tools.md)的卡片決定。

## 想加入自己的偏好？

在「補充內容」（自訂人設）的框裡寫下你希望 Lumi 記住的偏好，例如「叫我 Neil；回答時多用台灣用語」。

- 最多 2000 字，框下方會顯示「N / 2000」。超過時會提示，不能儲存。
- 留空就等於沒有補充。
- 補充的內容不能推翻基本規則（例如安全規則）。
- 按「還原預設」會把個性、積極度與補充內容都改回預設值，但要再按「儲存」才會生效。

## 怎麼換主題色和明暗？

1. 點左邊的「外觀與操作」。
2. 在「主題色票」點選一種，立即套用，只改顏色，不改版面：
   - **鼠尾草綠**（預設）：柔和、生活化、低刺激。
   - **清透藍綠**：清爽、友善、識別度高。
   - **霧藍色**：穩定、熟悉、有生產力工具的感覺。
   - **清亮靛藍**：現代、鮮明、有 AI 科技感。
   - **陶土色**：溫暖、有人文感。
3. 在「明暗」區塊的「顯示模式」選擇「跟隨系統」、「淺色」或「深色」。選「跟隨系統」時，系統切換深淺色，Lumi 也會一起切換。

## 怎麼讓工作台保持在最上層？

工作台的標題列有一個圖釘按鈕。點一下釘選後，其他視窗不會蓋住 Lumi；再點一次就取消。釘選的狀態會記住，下次打開還是釘選。

小精靈的位置與「永遠顯示在其他視窗上方」，設定在「小精靈」分類，見[小精靈](sprite.md)。

## 開機時要自動啟動嗎？

在「外觀與操作」的「啟動與更新」區塊，打開「開機後自動啟動 Lumi」，登入電腦後 Lumi 會自動開啟，並回到上次使用的模式（工作台或小精靈）。

如果這個選項是停用的，表示目前的執行方式無法設定開機自動啟動，請改用安裝後的正式版。

## 開啟 Lumi 時要不要檢查新版？

- **「開啟 Lumi 時檢查有沒有新版」**：打開時會查詢一次。只會查詢，**不會自動下載或安裝**；有新版時，工作台上方會出現提醒。
- **「立即檢查」**：馬上查詢，結果顯示在按鈕下方，例如「目前已是最新版。」或「有新版 N 可以下載。」

提醒上的按鈕：

- **看更新內容**：展開或收起這個版本的更新說明。
- **前往下載**：用瀏覽器開啟下載頁，由你自己下載安裝。
- **略過此版本**：之後不再為這個版本提醒；出現更新的版本時會再提醒。按「立即檢查」時，仍會顯示被略過的版本。
- **先關閉更新提醒**：這次先關掉，下次開啟 Lumi 會再提醒。

## 筆記資料夾在哪裡？

在「外觀與操作」的「筆記資料夾」區塊，可以指定每天的筆記要存到哪裡。每天的筆記是一個 Markdown 檔（檔名為日期，例如 `2026-11-06.md`），只會往後追加，不會改寫舊的內容。

- 可以直接指向 Obsidian 的 vault。Lumi 只讀寫日期檔，其他檔案不會動。
- 留空就使用預設位置；要用完整路徑，可以含環境變數，例如 `$HOME/Notes`。
- 按「恢復預設」就會回到預設位置。

請 Lumi 記筆記與查筆記的做法，見[記憶、筆記與過去的對話](memory.md)。

## 進階：顯示 token 用量

在「外觀與操作」最下面的「進階」可以打開「在每則回答下方顯示 token 用量」，用來估算費用。預設關閉，說明見[用量、費用與預算](usage-cost.md)。
