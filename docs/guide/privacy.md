# 資料與隱私

> 資料存在哪裡、哪些內容會送到 AI 供應商、金鑰怎麼保存、網路上還有誰會連到、怎麼刪除或關閉。

這一頁說明 Lumi 把什麼放在你的電腦上、什麼會離開你的電腦。實際的存放位置與大小，以 設定 › 資料與隱私 頁面上顯示的為準。

## 資料存在哪裡？

Lumi 的資料都放在你的電腦裡，不會自動上傳到別的地方。請打開 設定 › 資料與隱私 查看完整路徑，那裡可以按「在 Finder 顯示」（macOS）或「在檔案總管顯示」（Windows）打開位置，也能按「複製路徑」。位置會依系統與帳號不同。

那一頁列出十個存放位置：

1. **資料資料夾**：Lumi 的資料大多放在這裡。
2. **對話與記憶資料庫**：對話與訊息、長期記憶、提醒與排程、MCP 工具的快取，以及用量紀錄（用來計算費用）。
3. **圖片附件**：你在對話中貼上或加入的圖片。
4. **設定檔**：AI 連線、模型、人設、工具、外觀與網路等設定。不含 API 金鑰。
5. **API 金鑰與密碼**：見下一節。
6. **記錄檔**：程式的運作紀錄與錯誤，回報問題時可以附上。網路請求的紀錄裡會有網址（不含 `?` 後面的參數）。
7. **瀏覽器登入狀態**：Lumi 專用瀏覽器記住的登入資訊（Cookie）。
8. **角色素材**：你匯入的小精靈角色。
9. **技能資料夾**：你存的技能，一個技能一個資料夾，裡面是一般的文字檔（見[技能](skills.md)）。
10. **筆記資料夾**：Lumi 幫你記下的每日筆記，是一般的 Markdown 檔。

## 對話內容是明文儲存的嗎？

是的。對話與訊息存在「對話與記憶資料庫」裡，這個資料庫沒有加密，也沒有密碼保護。它只存在這台電腦上，但任何能用你的帳號開啟這台電腦、或拿到這個檔案的人，都可以直接讀到裡面的內容。因此建議：

- 電腦設定登入密碼，不要和別人共用同一個帳號。
- 備份或搬移電腦時，把這個資料庫當成敏感資料處理。
- 圖片附件與筆記也是一般檔案，沒有加密。

## API 金鑰怎麼保存？

金鑰不會寫進對話、資料庫、設定檔或記錄檔。

- **Windows**：金鑰存在 `secrets.json` 這個加密檔案裡，用你的 Windows 登入帳號加密，只有這個帳號在這台電腦上能解開。如果 Windows 密碼被管理員重設（不是你自己改），金鑰可能讀不出來，請重新輸入。
- **macOS**：金鑰存在系統的鑰匙圈，服務名稱會寫在 設定 › 資料與隱私 的說明裡。

MCP 伺服器需要的密碼與環境變數，也存在同一個地方。

## 哪些內容會送出去？

**送到 AI 供應商**

你在 AI 連線裡設定的供應商，會收到以下內容：

- 對話內容：你打的字與 Lumi 的回覆。
- 你加入對話的圖片與檔案內容。文字檔會整段帶入（太大的檔案不會帶入，模型會改用讀取工具分段讀），Word、Excel、PowerPoint、PDF 則不會直接帶入，而是在模型需要時由 Lumi 讀取。
- 長期記憶：每則訊息都會附上。
- 技能：技能清單（名稱與「什麼時候用」）每次請求都會附上；用到的技能全文，以及它讀取的技能參考檔，也會送出。
- 工具執行的結果，例如讀到的檔案內容或網頁內容。
- 系統指示與工具清單。

使用瀏覽器工具時，網頁內容與截圖也會送到供應商。產生或編輯圖片時，文字描述與圖片會送到你在「圖片生成」設定的連線。

如果你設定的 Base URL 指向這台電腦（例如 Ollama），內容就不會離開這台電腦。各家供應商怎麼保存與使用資料，請以他們的官方條款為準。

**其他會連線的地方**

| 功能 | 送出什麼 |
|---|---|
| 語音輸入 | 錄音，連同目前對話的編號，送到你設定的語音服務（Lumi 沒有內建語音辨識）。 |
| 網路工具 | 工具會直接連到網址。「讀取網頁」、「列出網頁連結」、「爬取網站」、「讀取 RSS」、「網路診斷」、「呼叫網路 API」會連到你或模型指定的網址；「送出資料到網路 API」每次都會先問你；「下載檔案」預設也會先問你，可以在 設定 › 工具 改成「永遠允許」。讀到的內容之後也會送到 AI 供應商。 |
| 瀏覽器 | Lumi 專用的瀏覽器，不會讀取你平常使用的瀏覽器的 Cookie 與密碼。瀏覽的網站會看到一般的網路請求。 |
| MCP | 「本機指令」的伺服器在你的電腦上執行，它會做什麼由它自己決定，只加入你信任的。「遠端 HTTP」的伺服器會收到工具呼叫時的參數。 |
| 執行指令 | 預設關閉。開啟後，你允許執行的指令在你的電腦上執行，會做什麼由指令決定（例如 `npm install` 會連到套件來源下載）。指令的輸出之後也會送到 AI 供應商。見[執行指令](commands.md)。 |
| 檢查更新 | 開啟 Lumi 時，連到 GitHub 查詢有沒有新版。只查版本，不會送出對話或檔案內容；GitHub 本來就會看到你的網路位址等一般連線資訊。不想要的話，可以到 設定 › 外觀與操作 取消勾選「開啟 Lumi 時檢查有沒有新版」。 |
| 更新價目表 | 只有在模型的「單價」設定裡按「更新價目表」時，才會下載公開的價目表。平時不會自動連線。 |

Lumi 的網路連線依 設定 › 網路 裡的 Proxy 設定進行，公司網路的情況見[網路與 Proxy](network.md)。

**檔案的讀取範圍**

Lumi 的檔案工具只讀取你加入對話的檔案與資料夾，以及你的筆記資料夾；開啟「執行指令」後，你允許的指令不受這個範圍限制。為了避免誤傳，加入的資料夾裡一些常見的機密檔會被排除，例如檔名是 `.env`（`.env.example` 這類範本除外）或 `secrets.json`、副檔名是 `.pem`、`.key`、`.pfx`、`.p12` 的檔案、`id_rsa`、`id_ed25519` 等開頭的私鑰，以及 `.ssh`、`.git` 資料夾裡的檔案。直接加入的單一檔案不會被這份名單擋住。這份名單不完整，其他檔案照常會讀，所以請不要把密碼或金鑰檔加進對話。

## 怎麼控制？

**刪除對話**

在工作台的歷史對話裡刪除一則對話，會清除：

- 這則對話的所有訊息，以及它的上下文整理紀錄。
- 這則對話中「這則對話都允許」所給的權限。
- 這則對話開啟的瀏覽器分頁。
- 不再被其他對話使用的圖片附件檔。

刪除不會影響：

- **費用紀錄**：用量與費用的紀錄會保留，已經花掉的錢不會消失。
- **長期記憶**：從這則對話記下的記憶仍然保留，要刪除請到 設定 › 記憶。
- **你原本的檔案**：Lumi 只清掉它自己複製的附件，不會動你電腦上的原檔。
- **筆記資料夾**裡的檔案。
- **提醒**。但如果某筆排程執行紀錄正是這則對話產生的，那筆紀錄會一起刪除。

**長期記憶**

打開 設定 › 記憶，可以關閉記憶、逐則刪除，或按「全部清除」。

**技能**

打開 設定 › 技能，可以停用、編輯或刪除個別技能。刪除會連附帶的檔案一起刪除。

**工具權限**

打開 設定 › 工具，可以關閉個別工具，或調整「確認方式」：預設是每次詢問，也可以改成「永遠允許」。寫進記憶的內容，以及會覆蓋或刪除內容的工具，一律會先問你。

**瀏覽器登入狀態**

打開 設定 › 網路，按「清除瀏覽器的登入狀態」。清除後，Lumi 專用瀏覽器裡的網站都要重新登入。

**提醒排程**

打開 設定 › 提醒排程，可以查看並刪除 Lumi 記得的提醒。

**語音服務**

打開 設定 › 語音，決定語音要送到哪個服務。不設定，語音就不會送出。

**記錄檔**

記錄檔可以直接刪除，不影響對話與設定。

目前 Lumi 沒有一鍵清除所有資料的功能。要完全移除，請先關閉 Lumi，再自行刪除資料資料夾、「圖片／Lumi」資料夾（產生或編輯的圖片），以及筆記資料夾（位置在 設定 › 資料與隱私 查看）。Windows 的金鑰檔 `secrets.json` 就放在資料資料夾裡，會一起刪除；macOS 的金鑰在鑰匙圈裡，要另外從鑰匙圈移除，服務名稱同樣在 設定 › 資料與隱私 查看（見「API 金鑰怎麼保存？」）。
