# AI 連線與模型

> 管理多個連線與模型：新增與測試連線、預設模型、對話中換模型、上下文上限與最大輸出怎麼調。

第一次設定 AI 連線的步驟在[開始使用](getting-started.md)。這一篇說明之後會用到的細節：多個連線與模型怎麼分工、換模型、進階欄位，以及怎麼刪除。

## 連線和模型是什麼關係？

- **連線**記錄要連到哪個 AI 服務、用哪一把 API 金鑰。
- **模型**是某個連線底下你想用的 AI 模型。一個連線底下可以有很多個模型，例如同一個 OpenAI 連線底下放一個便宜快速的模型、一個比較強的模型。

設定 › AI 連線的清單依連線分組：連線在上，它的模型縮排在下面，最後是虛線的「新增模型」。連線右邊的狀態是最近一次測試或對話的結果：「連線正常」「連線失敗」或「尚未確認」。目前的預設模型旁邊有「預設」標籤。清單最下面的「圖片生成」是另一組設定，見[圖片：貼上、產生與編輯](images.md)。

需要建立多個連線的情況：

- 同時使用不同供應商，例如 Anthropic 和 OpenAI。
- 同一個供應商有兩把金鑰（例如工作用和個人用），分成兩個連線，名稱取得好分辨。
- 同時用雲端服務和自己電腦上的 Ollama。

## 怎麼新增連線？

1. 打開設定，點「AI 連線」，再點右上角的「新增連線」。
2. 填「名稱」，只有你會看到。貼上「API 金鑰」；OpenAI 相容的服務（例如 Ollama）可以不填。
3. 需要時展開「進階」，確認「供應商格式」與「Base URL」。各家的填法見[開始使用](getting-started.md)的「常見服務怎麼填？」。
4. 按「測試連線」。這一步用的是畫面上的內容，不必先儲存。成功會顯示「成功 · 可用模型 N 個」。
5. 按「儲存」，再到這個連線底下新增模型。

已儲存的連線可以改名稱、網址或格式。金鑰存好後只顯示「已設定 · 結尾 xxxx」，要換時按「更換」貼上新金鑰；按「清除」會先確認，清除後這個連線沒有金鑰，直到你再貼上。改了網址、格式或金鑰後，原本的連線狀態會歸零，要重新測試。

### 「進階」裡的兩個欄位是什麼？

- **供應商格式**：決定 Lumi 用哪一種方式跟服務溝通，有「Anthropic 原生」和「OpenAI 相容」。多數第三方與本機服務都選「OpenAI 相容」。
- **Base URL**：服務的網址，要以 `http://` 或 `https://` 開頭。使用代理服務或相容端點時才需要改。如果填的是沒有加密的 `http://`，而且不是本機或內部網路的位址，Lumi 會警告金鑰會以明文傳送。網址填錯時的症狀見[常見問題與錯誤訊息](troubleshooting.md)。

## 怎麼新增模型？

1. 在清單裡，點連線底下的「新增模型」。
2. 在「模型 ID」選一個模型。清單來自這個連線的服務，旁邊的「重新整理」可以再取一次；取不到清單時（有些服務沒有提供），直接輸入模型 ID 也可以。
3. 「顯示名稱」只在 Lumi 裡顯示，實際送出的是模型 ID。你沒改過的話，它會跟著模型 ID 變。
4. 按「儲存」。

另外兩個選項：

- **顯示思考過程**：用「Anthropic 原生」連線時有作用，勾選後會要求模型提供思考過程的摘要，顯示在回覆裡。OpenAI 相容的連線，這個選項不會改變送出的請求。
- **使用工具**：預設勾選。模型不支援工具時（例如某些小型本機模型）才取消，取消後送出的請求不帶工具，這個模型也就不能用工具。見[工具與權限確認](tools.md)。

## 上下文上限與最大輸出是什麼？

兩個欄位在「進階」裡，單位都是 tokens。token 是模型計算文字量的單位，也是供應商計費的單位。

- **上下文上限**：模型一次能讀進去的內容長度。你的對話、加入的檔案、Lumi 給模型的指示都算在裡面。Lumi 用這個數字畫出工具列的用量圓環，也在對話用到約八成時自動整理前面的內容，見[用量、費用與預算](usage-cost.md)。填得比實際小，會比較早整理；填得比實際大，要等到模型讀不下才發現。
- **最大輸出**：模型單次回答最多寫多長。這個數字會直接送給服務，填得比模型允許的大，服務可能拒絕請求，畫面上會看到「請求內容不被伺服器接受」，處理方式見[常見問題與錯誤訊息](troubleshooting.md)。

新增模型時的預設值依連線格式而不同：

| 連線格式 | 最大輸出 | 上下文上限 | 顯示思考過程 |
|---|---|---|---|
| Anthropic 原生 | 64,000 | 1,000,000 | 勾選 |
| OpenAI 相容 | 4,096 | 128,000 | 不勾 |

預設值不一定符合你選的模型。實際數字請查供應商的模型說明頁，再自己填。

### 價目表會自動帶入嗎？

新增模型時，Lumi 會拿模型 ID 去比對內建的價目表。完全相符，或去掉日期與版本後綴後相符，就會一併帶入「上下文上限」、「最大輸出」和單價（單價見[用量、費用與預算](usage-cost.md)）。比對不到，或只有相近的候選時，兩個欄位維持預設值，要自己確認。新增到一半換連線，預設值也會跟著重新帶入。

編輯已存在的模型時，Lumi 不會改這兩個欄位。

### 舊模型的上下文上限會自動調高嗎？

會，但條件很窄，而且只調「上下文上限」，不動「最大輸出」。每次啟動 Lumi，以及按「更新價目表」之後，Lumi 會檢查每個模型，全部符合才調高：

- 連線的格式是「OpenAI 相容」。
- 上下文上限還是預設的 128,000。Lumi 無法分辨預設值和你自己剛好填的 128,000，所以這個數字都當成沒改過。
- 模型 ID 不在地端模型名單內（名單見[用量、費用與預算](usage-cost.md)）。
- 模型 ID 在價目表裡完全相符，或去掉日期與版本後相符，而且價目表的數字比較大。

只調高，不會調低。最大輸出不會自動改，需要的話自己到模型的「進階」調整。

## 預設模型是什麼？怎麼換？

「預設模型」是 Lumi 目前使用的模型，工作台與小精靈共用同一個。

換模型有兩個地方，效果相同：

- **設定 › AI 連線最上方的「預設模型」下拉選單**：選了立即生效，不用按儲存。
- **工作台上方的模型按鈕**：按鈕上寫著「連線名稱 · 模型 ID」，點開可以搜尋、依連線分組選擇，最下面的「管理連線與模型…」會開啟設定。

換模型之後，目前這則對話和之後的新對話都會用新的模型。要注意的事：

- Lumi 正在回應時不能換，按鈕會停用，要等回應結束或先停止。
- 這則對話的前文已經很長（約 2 萬 tokens 以上）時，選模型後會先出現確認區，提醒換模型後前文要重新送一次、費用比較高。可以選「開新對話再換」或「照樣換」。每則對話只會問一次。
- 第一個新增的模型會自動成為預設。如果原本的預設模型已經不能用（被刪除，或連線沒有金鑰），新增模型時會自動改用新模型，並顯示說明。
- 刪除的剛好是預設模型時，預設會改成剩下的其中一個，畫面會顯示「預設模型已改為…」；沒有模型了就是「未設定」。

## 怎麼刪除連線或模型？

- **刪除模型**：點清單裡的模型，按「刪除」，確認後只刪這一個模型設定，連線不受影響。
- **刪除連線**：點連線，按「刪除」。確認視窗會寫出底下有幾個模型，確認後這些模型與這個連線的金鑰都會一併刪除。

還沒儲存的新連線或新模型，按「刪除」就是放棄。切換到別的項目時，如果有沒存的變更，Lumi 會先問你要不要放棄。
