# 用量、費用與預算

> 看本月花費、設定預算、單價與不計費，以及上下文快滿時怎麼辦。

Lumi 會記錄每次請求用了多少 token（用量單位），並依各模型的單價估算費用。這些金額是估算，實際費用以供應商的帳單為準。

## 工具列的圓環是什麼？

工作台工具列上的小圓環，表示「這則對話目前用了模型能讀長度的多少」，這個長度叫做**上下文**。數字是最近一次請求送出的內容加上回覆的長度，除以模型的上下文上限。

- 用到 60% 以上會顯示「已用超過一半」。
- 用到 85% 以上會顯示「快滿了，建議開新對話」，同時面板會出現提醒。
- 滑鼠停在圓環上會顯示百分比，例如「上下文 9% · 點一下看詳情」。

上下文上限沒有填或不知道時，圓環不會顯示百分比，只顯示用掉的數字。上限在設定 › AI 連線裡，見[AI 連線與模型](connections.md)。

## 這個對話用了多少？

點一下圓環，會打開「本對話用量」面板：

- **上下文**：百分比、已用與上限、還可以再用多少。
- **輸入、輸出、回合**：這則對話累計的 token 數與你送出的次數。輸入包含快取的部分，「快取」的百分比是其中被快取命中的比例。
- **本對話、本月**：這則對話與本月的估算費用。有設定預算時，本月會一起顯示「已用金額 ／ 預算」。
- **模型與連線**：目前使用的模型與連線狀態。連線失敗時可以按「重試」。

面板底下的「用量與費用 ›」會打開設定 › 用量與費用。

如果想在每則回答下面看到這則回答的輸入與輸出 token 數，到設定 › 外觀與操作，在最下面的「進階」勾選「在每則回答下方顯示 token 用量」。預設關閉。

## 這個月花了多少錢？在哪裡看？

1. 打開設定，點左邊的「用量與費用」。
2. 最上面的大數字是本月金額，從每月 1 日算到今天。下面的日期範圍和「約 US$」是同一筆金額的美元數字。
3. 下面的「每天」長條圖顯示每一天的花費，滑鼠停在長條上可以看到金額。
4. 「花最多的對話」列出本月花最多的 5 則對話，點了會開啟該對話。
5. 「這個月出現過的情況」列出本月觸發過的使用提醒，見下面的[輸入框上方的提示](#輸入框上方的提示是什麼)。

本月還沒有用量時，頁面只顯示「這個月還沒有用量。」

除了對話本身，每則新對話還會多一次很小的請求，用來自動取標題（只送第一則訊息的文字，回答只有一行），也算在本月用量裡。訊息很短時不會多這一次。

## 金額前面的「≈」是什麼意思？

金額前有「≈」，表示其中有一部分是估算的。常見原因是回應中途被停止、失敗，或供應商沒有回報用量；這時 Lumi 會依文字內容估算 token 數。

金額換算採固定匯率，**1 美元 ＝ 32 新台幣**。費用在資料中是美元，畫面上換成新台幣顯示，需要美元數字時請看匯出的明細。

## 費用為什麼是 0？

- **這個模型被設定為「不計費」**：用量照常記錄，費用算 0。地端模型常見，見下面的[不計費](#不計費是什麼)。
- **本月還沒有用量**：還沒送出任何請求。
- **顯示「未設定單價」**：這個模型沒有單價，請求的用量有記錄，但沒有計入金額。到設定 › AI 連線，打開該模型，設定單價。

設定 › 用量與費用的本月卡片會顯示「有 N 次請求的模型未設定單價，沒有計入。」，就是這個情況。

## 單價從哪裡來？

新增或打開模型時，Lumi 會拿模型 ID 去比對內建的價目表：

- **已自動帶入**：模型 ID 和價目表完全相同（不分大小寫），或只差日期、版本後綴、供應商前綴這類寫法，就自動填入單價，並標示「已自動帶入」。
- **候選**：只有名稱相近的模型時，Lumi 會列出最多 3 個候選，請你自己選一個按「套用」，或按「自己填」。候選不會自動套用。
- **找不到**：價目表裡沒有，單價欄位留空，請自己填入「輸入」與「輸出」的每百萬 tokens 單價（美元）。快取價格在「進階：快取價格」裡，留空時以輸入價計算。

要點的細節：

- 你自己改過的單價不會被自動覆蓋；改了模型 ID 才會重新比對。
- 改了單價只影響之後的請求，之前的紀錄不變。
- 自動帶入的單價可以按「還原自動帶入的單價」。
- 要更新價目表，在模型的「單價」區按「更新價目表」。這需要能連到網路；失敗時會繼續使用目前的價目表。

## 不計費是什麼？

地端模型（在自己的電腦或內部伺服器上執行的開源模型）不需要向供應商付費，所以可以勾選「不計費（例如地端模型）」，用量照常記錄，費用算 0。

Lumi 會依模型名稱自動勾選常見的地端模型，例如 Qwen、Llama、Gemma、Mistral、Phi、GLM、gpt-oss 等系列。**雲端服務不會自動勾選**，例如 DeepSeek 的 API 是雲端服務，要照供應商的價格計費。

- 自動勾選後，你可以取消勾選；取消後，同一個模型 ID 不會再被自動勾回來。
- 自動勾選的情況下，把模型 ID 改成非地端的模型名稱，自動勾選會取消。
- 名單會隨 Lumi 版本更新，但**已經勾選的舊模型不會因此自動取消**，要的話請自己取消勾選。

## 怎麼設定每月預算？

1. 打開設定 › 用量與費用。
2. 按「設定每月預算」（已經設定過時是「編輯」）。
3. 在「每月預算（新台幣）」輸入大於 0 的整數金額，按「儲存」。

要取消預算，按「編輯」再按「不設預算」。預算只用來提醒，不會限制用量。

## 超過預算會怎樣？

每次回應結束後，Lumi 會檢查本月金額，並在工作台頂端顯示提醒：

- 用到預算的 **80%**：「這個月的 AI 費用已經用到預算的 80%」。
- 用到 **100%**：「這個月的 AI 費用已經超過預算」。Lumi 會繼續回應，不會停止。要限制花費，請到供應商的後台設定上限。

同一個門檻每個月只提醒一次。提醒列上的「查看用量」會打開設定 › 用量與費用，「知道了」會關掉它。

本月卡片下面會顯示預測「照目前的速度，月底約 NT$…」；有預算且會超過時改寫成「會超過預算」。本月有紀錄的天數少於 7 天時不做預測。

## 輸入框上方的提示是什麼？

輸入框上方偶爾會出現一行提示，例如「對話的前文已經很長」或「啟用的工具說明太多」，並附上可以按的動作。提示只在工作台出現，小精靈模式不顯示。

- 「知道了」：關掉這一則。
- 「不再提醒這類」：這一類提示之後都不再出現。要恢復，到設定 › 用量與費用，在「這個月出現過的情況」那一類按「重新開啟」。

提示可能包括：對話的前文很長、大檔案或圖片留在前文裡、啟用太多工具、一直重新產生、要求整份重寫、同一份內容反覆貼上、隔很久才回到長對話。它們的目的是提醒你可以省用量，不影響回答。

## 上下文快滿了怎麼辦？

圓環到 85% 以上時，面板會出現提醒，並有三個按鈕：

- **整理並繼續**：Lumi 立刻把前面的對話整理成摘要，之後的回答以摘要為基礎繼續。對話畫面會出現「以上內容已整理成摘要」，可以按「查看摘要」。回應進行中時這個按鈕不能按。
- **開新對話**：從空白開始，原來的對話保留在歷史紀錄裡。換話題時最省。
- **繼續這則**：只關掉面板，對話照常進行。

Lumi 也會在送出前自動整理：估算用量超過上限的 80% 時，先清掉舊的工具結果；仍然超過 70% 時，再整理成摘要。整理失敗時，畫面會顯示「整理對話失敗，對話內容沒有改變」，可以稍後再試，或開新對話。

## 怎麼匯出明細？

1. 打開設定 › 用量與費用。
2. 按「匯出明細（CSV）」，選擇要存的位置。檔名是「Lumi-用量-年-月.csv」，例如 Lumi-用量-2026-11.csv。
3. 頁面底下會顯示「已匯出到…」。

CSV 每一列是一次請求，欄位包括時間、對話標題、用途（對話、整理或標題）、模式（工作台或小精靈）、連線、模型 ID、各種 token 數、是否估算、單價快照，以及「費用（US$）」。
