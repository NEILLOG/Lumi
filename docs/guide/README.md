# Lumi 使用教學

Lumi 是在電腦桌面上執行的 AI 助理，這裡是它的使用說明。

第一次使用請先看 [開始使用](getting-started.md)。

## 基本操作

- [開始使用](getting-started.md)：第一次打開 Lumi：接上 AI 模型、送出第一則對話。
- [常見問題與錯誤訊息](troubleshooting.md)：看到錯誤訊息或功能不能用時，查這裡的原因與處理方式。
- [對話與歷史紀錄](chat.md)：工作台怎麼用：送出、停止、重新產生、開新對話、找以前的對話。
- [加入檔案與資料夾](files.md)：讓 Lumi 讀檔案、資料夾、Word、Excel、PDF，以及寫入檔案時會發生什麼。
- [語音輸入](voice.md)：設定語音服務、用說的輸入，以及麥克風按鈕不能按的原因。

## 設定與連線

- [AI 連線與模型](connections.md)：新增連線與 API 金鑰、選模型、Base URL、上下文上限。
- [網路與 Proxy](network.md)：公司網路連不上時的 Proxy、PAC 設定，以及 Lumi 能怎麼讀網路。
- [用量、費用與預算](usage-cost.md)：看本月花費、設定預算、單價與不計費，以及上下文快滿時怎麼辦。
- [資料與隱私](privacy.md)：資料存在哪裡、哪些內容會送出去、怎麼控制與刪除。

## 個性與記憶

- [調整 Lumi 的個性與外觀](personalize.md)：個性、主動程度、自訂人設、主題色、開機啟動與檢查更新。
- [記憶、筆記與過去的對話](memory.md)：讓 Lumi 記住偏好、記筆記、參考最近的對話、查以前說過的事。

## 工具與外部功能

- [工具與權限確認](tools.md)：Lumi 能用哪些工具、確認按鈕的差別、永遠允許、開關工具。
- [讓 Lumi 操作瀏覽器](browser.md)：用 Edge 或 Chrome 開網頁、點擊、填表，以及登入狀態怎麼處理。
- [連接外部工具（MCP）](mcp.md)：MCP 是什麼、需不需要、怎麼新增伺服器，以及有什麼風險。
- [提醒、計時器與排程](reminders.md)：請 Lumi 提醒你、開計時器、排定時間自動做事，以及看排程紀錄。
- [圖片：貼上、產生與編輯](images.md)：給 Lumi 看圖片、請它產生或編輯圖片，以及費用與存放位置。

## 角色與趣味

- [小精靈](sprite.md)：桌面小精靈怎麼用、換角色與大小、匯入角色、工作台裡的小精靈。
- [塔羅牌](tarot.md)：請 Lumi 抽塔羅牌、看牌面與牌義。
