# 圖片：貼上、產生與編輯

> 給 Lumi 看圖片、請它產生或編輯圖片，以及費用與存放位置。

Lumi 可以看你給它的圖片，也可以請它用 AI 畫新圖或修改既有的圖。看圖是模型直接讀取圖片內容；產生與編輯圖片則要另外連到一個圖片生成服務，會產生費用。

## 怎麼把圖片給 Lumi 看？

有三種方式，圖片都會加進輸入框上方的「此對話的上下文」：

1. **貼上截圖**：截圖後，回到 Lumi 的輸入框按 Ctrl+V（macOS 按 Cmd+V）。剪貼簿裡有圖片時，Lumi 會把它存起來，名稱是「貼上的截圖」加上時間。剪貼簿裡只有文字時，就是一般的貼上。
2. **拖放**：從檔案總管（Windows）或 Finder（macOS）把圖片檔拖進工作台的輸入區，放開即可。
3. **加入檔案**：按輸入框下方的「加入檔案」，選一張或多張圖片。

Lumi 看的是檔案的內容，不是副檔名。支援的格式是 PNG、JPEG、GIF、WebP，每張圖片不能超過 5 MB。超過大小或格式不對時，該圖片旁會標示「圖片太大」或「不支援的圖片格式」，這張圖不會送出。

送出前，Lumi 會把比較大的圖片縮小到長邊約 1568 像素，讓傳輸與費用都比較省。GIF 和無法縮小的圖片會維持原樣送出。

圖片和文字一樣，會送到你設定的 AI 供應商，見[資料與隱私](privacy.md)。

## 送出圖片後，Lumi 回答不了怎麼辦？

有些模型不支援看圖，例如某些小型的本機模型。送出後如果出現錯誤，原因可能是這個模型不能看圖。處理方式：

1. 把圖片從「此對話的上下文」移除（每個項目旁邊都有「移除」）。
2. 換一個支援圖片的模型，或重新送出不含圖片的問題。

錯誤訊息的完整說明與其他原因，見[常見問題與錯誤訊息](troubleshooting.md#請求被拒)。

## 圖片會一直留在對話裡嗎？

會。圖片留在對話的前文裡，之後每一輪送出時都會重新送給模型，一張圖片會持續增加用量。看完了的圖片，可以開新對話，或整理對話後再繼續。用量的說明見[用量、費用與預算](usage-cost.md)。

## 怎麼設定圖片生成？

要請 Lumi 產生或編輯圖片，先設定圖片生成。這個設定和對話用的模型是分開的，可以用不同的連線。

1. 點右上角的齒輪，打開設定，進入「AI 連線」。
2. 在連線清單的最下方，點「圖片生成」。沒有設定時，這一列會顯示「尚未設定」。
3. 在「連線」選一個連線。圖片生成需要「供應商格式」是「OpenAI 相容」的連線；如果你的連線是「Anthropic 原生」格式，請先到 AI 連線新增一個 OpenAI 相容的連線。
4. 在「模型 ID」選擇或輸入圖片生成的模型。按「重新整理」可以取得清單，但清單不一定列得出圖片模型，這時直接輸入模型 ID 即可，ID 請照供應商的文件填。
5. 在「預設尺寸」選一種：正方形 1024 x 1024、橫向 1536 x 1024，或直向 1024 x 1536。
6. 按「儲存」。這一列會變成「連線名稱 · 模型 ID」。

刪除這個連線時，圖片生成會回到「尚未設定」。

## 怎麼請 Lumi 產生圖片？

設定好之後，在工作台直接說想畫什麼，例如：

- 「幫我畫一張在海邊看夕陽的貓，水彩風格。」
- 「畫一張橫向的會議室示意圖，簡潔一點。」

Lumi 會呼叫「產生圖片」工具。說得越具體，結果越接近你要的：主體、風格、構圖、顏色都可以寫進去。尺寸沒有指定時，用設定裡的預設尺寸；你也可以說「直向」或「橫向」。

產生圖片預設會先跳出確認卡片，列出要畫的內容與尺寸，按確認後才會執行。確認方式可以到設定 › 工具調整。

產生時，對話中會出現「正在產生圖片…」與已經等待的秒數。通常需要 10 秒到幾分鐘。完成後，圖片會以縮圖顯示在回覆的上方。

## 怎麼請 Lumi 修改或合成圖片？

編輯圖片的做法是：先讓 Lumi 拿到原圖，再說要怎麼改。例如：

- 「把這張照片的背景換成海邊。」
- 「把這兩張圖合成一張，左邊是產品，右邊是包裝。」

來源圖片可以是下列其中一種，最多 4 張：

- 你在這則對話貼上或加入的圖片。
- 這則對話裡 Lumi 先前產生或編輯的圖片。
- 你加入到對話裡的圖片檔。

編輯的來源只能是 PNG、JPEG 或 WebP，GIF 不行；每張不能超過 20 MB。編輯會產生新檔，原圖不會被改動。編輯圖片同樣預設會先跳出確認卡片。

## 產生或編輯的圖片存在哪裡？

都存在你電腦的「圖片」資料夾底下的 Lumi 資料夾，也就是「圖片／Lumi」。例如在 Windows 會是 `圖片\Lumi`，在 macOS 是 `~/Pictures/Lumi`。

- 產生的圖片檔名是年月日加時間，例如 `20261106-143005.png`。
- 編輯的圖片檔名會多一個 `-edit`，例如 `20261106-143510-edit.png`。
- 同一秒產生多張時，會自動加上 `-2`、`-3`。

圖片不會再送回給模型看，Lumi 只記得檔案的位置。要再修改這張圖，請它用「編輯圖片」，並指定這個檔案。

回覆上的縮圖可以這樣操作：

- 點縮圖，或按「放大檢視」，用看圖視窗開啟。
- 在看圖視窗中，可以用「放大」「縮小」「符合視窗」「100%」調整大小，也可以用滑鼠滾輪縮放、拖曳移動，或按兩下切換。
- 按「用其他程式開啟」可以用電腦上預設的看圖程式開啟；按「開啟資料夾」會打開圖片所在的資料夾。

## 產生與編輯會產生費用嗎？

會。圖片是由你設定的圖片生成服務處理，費用由那個服務的供應商依張數與尺寸計算，從你的帳號扣款，Lumi 不收費。

請注意：「設定 › 用量與費用」目前不會計入圖片生成與編輯的費用，只計入對話本身的用量。想知道圖片花了多少錢，請到該供應商的後台查看。

## 產生與編輯圖片能在小精靈用嗎？

不能，這兩個工具只能在工作台使用。想畫圖或改圖，請切換到工作台再請 Lumi 做。

## 怎麼關閉圖片相關的工具？

到設定 › 工具，在「圖片」群組關閉「產生圖片」或「編輯圖片」。關閉後，從下一則新對話開始生效。關閉工具不會影響你貼上或拖放圖片給 Lumi 看。
