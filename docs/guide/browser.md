# 讓 Lumi 操作瀏覽器

> Lumi 可以用電腦上的 Edge 或 Chrome 開網頁、點擊、填表、下載檔案；登入狀態存在專用設定檔，不會讀你平常瀏覽器的資料。

## Lumi 能用瀏覽器做什麼？

有些網站需要登入、需要執行網頁程式，或要點按鈕、填表單才看得到內容，光「讀取網頁」讀不到。這時 Lumi 會改用瀏覽器：

- 開啟網址，看網頁上有哪些按鈕、連結與欄位。
- 點擊、輸入文字、按鍵、選擇下拉選單、捲動、回上一頁。
- 擷取網頁的文字或表格，必要時對網頁截圖。
- 點下載連結，把檔案存進你加入的資料夾；把你加入的檔案上傳到網頁。
- 遇到登入或驗證碼，停下來請你自己處理。

只是想讀一篇文章或文件，Lumi 會優先用比較快的「讀取網頁」，不會開瀏覽器。Lumi 沒有網路搜尋功能：想查資料時，請直接給它網址。

試試看：說「打開 https://example.com，告訴我頁面上寫了什麼」。Lumi 會先用「開啟網頁」打開網址，再讀取內容回答你。

所有瀏覽器工具的名稱、權限與說明，見[工具與權限確認](tools.md)。

## 需要先安裝什麼？

Lumi 不會另外下載瀏覽器，而是用你電腦上已經安裝的 Microsoft Edge 或 Google Chrome。Windows 與 macOS 都可以。

兩個都沒有安裝時，瀏覽器工具會失敗，請先安裝其中一個，建議 Microsoft Edge。

## 怎麼選瀏覽器、顯示瀏覽器視窗？

瀏覽器的設定在設定 › 網路的最下面，「瀏覽器」區段。

1. 點右上角的齒輪打開設定視窗，點左邊的「網路」，往下捲到「瀏覽器」。
2. 「使用的瀏覽器」有三個選項：「自動（Edge 優先，其次 Chrome）」「Microsoft Edge」「Google Chrome」。預設是自動。
3. 選項下面會寫「找到：Microsoft Edge …」，列出偵測到的瀏覽器。剛安裝或剛移除瀏覽器時，按「重新偵測」。找不到時這一行會變成警告。
4. 想看 Lumi 的每一步操作，勾選「顯示瀏覽器視窗」。預設不勾，瀏覽器在背景執行，你看不到視窗。

這些設定改了就生效，沒有「儲存」按鈕；已經開著的瀏覽器要等到下次開啟時才套用。瀏覽器會沿用同一頁上方的 Proxy 設定，見[網路與 Proxy](network.md)。

## 需要登入時怎麼辦？

Lumi 不會自己輸入密碼。「輸入文字」不能填密碼欄位，遇到登入或驗證碼時，Lumi 會用「等待使用者操作」請你自己處理：

1. 卡片上會寫著要你做什麼，例如請你登入，以及要等到什麼條件才繼續，最多等多久（預設 180 秒）。請看過按「允許一次」。
2. Lumi 會打開瀏覽器視窗，這時視窗一定會出現，不看「顯示瀏覽器視窗」的設定。
3. 在視窗裡自己登入或完成驗證。
4. 頁面符合 Lumi 指定的完成條件（網址包含某段文字，或頁面出現某段文字）後，Lumi 會自動接著做。時間到了還沒完成，Lumi 會停止等待，你可以再請它試一次。

為了顯示視窗，瀏覽器可能會重新啟動並重新載入頁面，沒送出的表單內容可能不見，請在 Lumi 接手前先處理好登入。

## 登入狀態存在哪裡？

Lumi 使用自己專用的瀏覽器設定檔，不會讀取你平常使用的 Edge 或 Chrome 的 Cookie 與密碼，也不會看到你在平常瀏覽器裡的登入狀態。

在 Lumi 的瀏覽器登入過的網站，登入狀態會保留，下次不用重新登入，直到你清除為止。Edge 與 Chrome 各有一份，換瀏覽器就要重新登入。這些登入狀態屬於敏感資料，放在 Lumi 的資料資料夾裡，位置見[資料與隱私](privacy.md)。

要清除：

1. 打開設定 › 網路，往下捲到「瀏覽器」的「登入狀態」。
2. 按「清除瀏覽器的登入狀態」。
3. 確認視窗寫著清除後，Lumi 的瀏覽器裡所有網站都要重新登入；按「清除」。完成後會顯示「已清除瀏覽器的登入狀態。」

清除會一併刪掉 Edge 與 Chrome 兩份設定檔，並關閉 Lumi 的瀏覽器。

## 會有什麼資料送到哪裡？

使用瀏覽器工具時，Lumi 讀到的頁面內容與截圖，會送到你目前使用的模型供應商，讓模型判斷下一步。登入後的頁面也一樣，所以不要在不想讓模型看到的頁面上使用。「輸入文字」要輸入的內容，也是模型決定的，會連同頁面一起經過模型。

送到供應商的資料與保存位置，整理在[資料與隱私](privacy.md)。

## 它操作之前會先問我嗎？

會。瀏覽器工具的權限等級如下，確認卡片的按鈕與規則見[工具與權限確認](tools.md)：

- 「開啟網頁」是「網路」等級。Lumi 要開你沒提過的網站，卡片會多一則黃底警告，請你確認；搜尋引擎的網址每次都問。
- 「點擊」「輸入文字」「按鍵」「選擇選項」「回上一頁」是「寫入」等級。點擊可能送出表單或改變網站上的資料，請看清楚卡片上寫的對象再允許。
- 「輸入文字」的卡片不會顯示輸入的內容（可能含個人資料），只寫輸入幾個字、是否按 Enter 送出。
- 「查看網頁」「捲動網頁」「擷取網頁內容」「網頁截圖」「關閉瀏覽器分頁」只讀取或關閉，不會問。
- 「上傳檔案」與「等待使用者操作」不能設成「永遠允許」。

選「本次對話都允許」時，瀏覽器工具另外記：只連帶同一權限等級的其他瀏覽器工具，不會連帶「寫入檔案」這類非瀏覽器的工具。

## 下載與上傳檔案有什麼限制？

這兩個動作都只能用你加入對話的資料夾與檔案，見[加入檔案與資料夾](files.md)。

- 下載：把檔案存到你加入的資料夾；不會覆蓋已存在的檔案，單檔最多 200 MB，不能下載執行檔與安裝檔。需要登入才能下載的檔案用瀏覽器下載；一般網址 Lumi 會用「下載檔案」（網路群組）直接下載。
- 上傳：檔案必須在你加入的範圍內，單檔最多 50 MB。上傳會把檔案送給該網站，卡片會寫出檔名與網站。
- 「爬取網站」遇到需要登入的網站時，也可以用 Lumi 瀏覽器裡的登入狀態。

## 為什麼小精靈不能操作瀏覽器？

所有瀏覽器工具都只能在工作台使用，沒有例外。在小精靈要 Lumi 開網頁會失敗；切到工作台再做一次就可以，失敗時的處理見[常見問題與錯誤訊息](troubleshooting.md)。

## 瀏覽器什麼時候會關閉？

- 第一次需要時才會啟動，Lumi 開啟時不會先開。
- 每則對話有自己的分頁，一則對話最多 3 個分頁，全部對話合計最多 8 個；超過時會關掉最久沒用的對話的分頁。
- 所有對話都超過 10 分鐘沒有使用，瀏覽器會自動關閉；之後 Lumi 會重新開啟。
- 對話中可以請 Lumi 關閉這則對話的分頁，登入狀態仍然保留。
- 結束 Lumi 時，瀏覽器一起關閉。
