# 小精靈

> 桌面小精靈怎麼切換、怎麼問問題、怎麼換角色與大小、怎麼匯入自己的角色，以及工作台裡的小精靈怎麼關。

Lumi 有兩種畫面：工作台是完整的對話視窗，小精靈是待在桌面角落的小角色，用一個小氣泡回答。兩種畫面用的是同一組 AI 連線與設定，同一時間只會顯示其中一個。

## 工作台和小精靈有什麼不同？

- **工作台**：完整的對話視窗，可以看長的回答、加入檔案，也能使用瀏覽器、寫入檔案等工具。
- **小精靈**：桌面上的角色與小氣泡，適合問一句、回一小段。能用的工具比工作台少，瀏覽器、寫入檔案等工具只能在工作台使用。

小精靈有自己的一則專屬對話。切到小精靈模式時，Lumi 會記下工作台目前的對話，開啟小精靈的專屬對話；回到工作台時，再接回原本那一則。下次開啟 Lumi 時，會回到你上次關閉時的模式。

## 怎麼切換到小精靈模式？

1. 在工作台上方的標題列，按「小精靈模式」。視窗較窄時只剩圖示，滑鼠停在上面也會顯示同樣的文字。
2. 工作台會隱藏，小精靈會出現在桌面角落。

Lumi 正在回應時，這個按鈕會停用，滑鼠停上去會顯示「回應中，暫時無法切換」。等回應結束再切換。

## 怎麼回到工作台？

以下任何一種方法都可以：

1. 在小精靈上按右鍵，選「開啟工作台」。
2. 在氣泡上按「在工作台開啟完整內容」，工作台會開在那一段內容的位置。
3. 在 Windows 的右下角通知區域，或 macOS 上方的選單列，點 Lumi 的圖示，選「開啟工作台」。

如果小精靈正在回應，工作台會先以唯讀的「查看中」狀態打開，等回應結束才切換成工作台模式。

## 小精靈模式怎麼問問題？

1. 把滑鼠靠近小精靈，它下方的輸入框就會出現，框裡的提示是「問小精靈…」。
2. 輸入想問的話，按 Enter 送出。按 Esc 可以清空輸入框。
3. 回應進行中，輸入框只能打草稿，不能送出；等回應結束再按 Enter。
4. 回答會以氣泡出現。回應進行中，氣泡會顯示「思考中…」或正在做的事。
5. 回答完成後，氣泡會慢慢淡出；把游標停在氣泡上就會暫停淡出。

## 為什麼小精靈的回答很短？

小精靈模式的回答限制很嚴：大約兩句話、六十字以內，只用純文字，不使用清單、表格或程式碼區塊。氣泡只放得下一小段，所以 Lumi 會把答案寫短。

需要較長的內容時（程式碼、步驟、清單、表格、長篇的說明或翻譯），Lumi 會把完整內容放到工作台的一張「內容卡」裡，氣泡只留一句重點。氣泡上會出現「在工作台開啟完整內容」，點它就會切到工作台，並捲到那張內容卡。即使你要求詳細說明，也是一樣的做法。

如果你想直接看完整答案，也可以回工作台，問同樣的問題。

「整理完整內容」是小精靈專用的工具，它的說明見[工具與權限確認](tools.md)。

## 小精靈的氣泡上有哪些按鈕？

**需要確認的操作**

小精靈要執行需要你同意的工具時，氣泡會顯示「要執行「…」嗎？」，並有以下按鈕：

- 「允許」：只允許這一次。
- 「拒絕」：不執行，Lumi 會接著回答。
- 「更多選項」：展開後會有「允許一次」、「這則對話都允許」、「拒絕」，以及「在工作台檢視」。「這則對話都允許」只有部分操作才會出現。

會刪除或覆蓋內容、無法復原的操作，氣泡會寫「無法復原」，按鈕改成「允許刪除」與「拒絕」。確認後，氣泡會顯示「已允許」或「已拒絕」與操作名稱。

**錯誤**

回應失敗時，氣泡會以紅字顯示錯誤原因，並依情況提供按鈕：

- 「重試」：錯誤可以重試時出現。
- 「開啟設定」：金鑰或模型設定有問題時出現。存好金鑰後，Lumi 會自動重送剛才的問題。
- 「在工作台查看」：到工作台看完整的錯誤與對話。

錯誤的原文與處理方式，見[常見問題與錯誤訊息](troubleshooting.md)。

## 小精靈的動畫代表什麼？

小精靈會用動作表示現在在做什麼。不同角色的畫法可能不同；想看每個狀態長什麼樣子，可以到 設定 › 小精靈 的「狀態預覽」，點一個狀態就會在左邊播放。角色沒有某個狀態的專屬畫法時，會改用相近的狀態，預覽上會寫明「沒有專屬表現，改用「…」」。

| 狀態 | 什麼時候看到 |
|---|---|
| 待機 | 沒有工作，等你開口 |
| 聆聽 | 正在用語音輸入錄音 |
| 轉寫 | 正在把錄音轉成文字 |
| 思考 | 已送出問題，還沒開始回答 |
| 呼叫工具 | 正在使用工具，例如讀取檔案 |
| 回覆中 | 回答正在一段一段出現 |
| 完成 | 回答結束，過幾秒後回到待機 |
| 需要確認 | 有操作等你按「允許」或「拒絕」 |
| 錯誤 | 出錯了，請看氣泡上的說明 |
| 休眠 | 一分鐘左右沒有動靜就會休眠；滑鼠靠近或再有操作就會醒來 |

## 工作台裡的小精靈可以關掉嗎？

可以。工作台的新對話歡迎區與工具列旁，會有一個小角色陪著你，它只是裝飾，關掉不影響任何功能。

1. 點右上角的齒輪，打開「設定」。
2. 點左邊的「小精靈」。
3. 在「在工作台顯示小精靈」那一項，取消勾選「顯示」。

工作台裡的小精靈大小固定，不受設定裡的「大小」影響。

## 怎麼換角色？

1. 打開 設定 › 小精靈。也可以在小精靈上按右鍵，選「切換角色…」。
2. 在「角色」清單裡點一個角色卡片。
3. 換角色立即生效，小精靈視窗的位置不會移動。

每張角色卡片會顯示名稱、作者與版本，以及「程式型」或「素材型」。Lumi 內建的角色是「光球」。

## 怎麼改大小？

打開 設定 › 小精靈，在「大小」的下拉選單選「小（64）」、「中（80，預設）」或「大（104）」。數字是角色的大小，以光球直徑為準。切換大小時，小精靈的位置不會跳動。

## 怎麼讓小精靈不被其他視窗蓋住？

打開 設定 › 小精靈，在「顯示位置」勾選或取消「永遠顯示在其他視窗上方」。取消後，小精靈會像一般視窗一樣，被其他視窗蓋住。

## 怎麼讓小精靈的回答帶上角色語氣？

打開 設定 › 小精靈，在「角色語氣」勾選「讓小精靈的回答帶上角色語氣」。

- 語氣只影響說話風格，不影響小精靈能做的事、規則或回答長度。
- 語氣和角色的人設衝突時，以人設為準。
- 只有部分角色有語氣設定；目前的角色沒有時，這裡會寫「目前的角色沒有語氣設定。」
- 語氣只在小精靈模式使用，工作台不受影響。

## 怎麼暫時隱藏小精靈？

在小精靈上按右鍵，選「暫時隱藏 30 分鐘」。時間到會自動出現；想提早叫回來，在 Windows 的通知區域或 macOS 的選單列點 Lumi 圖示，選「顯示小精靈」。

## 怎麼匯入自己的角色？

1. 打開 設定 › 小精靈，按「開啟角色資料夾」，會開啟存放角色的資料夾。
2. 把角色放進這個資料夾。每個角色一個子資料夾，裡面是 `manifest.json` 與圖片。
3. 回到設定，按「重新載入」（載入時會顯示「載入中…」）。
4. 新角色會出現在「角色」清單，點它的卡片就能使用。

角色資料夾的位置也列在 [資料與隱私](privacy.md) 的「角色素材」裡。

**載入失敗怎麼辦？**

設定 › 小精靈 的「載入失敗與警告」會列出問題，每一項都標明是「載入失敗」或「警告」：

- 「載入失敗」的角色不會出現在清單裡。照說明修正後，按「重新載入」。
- 「警告」的角色仍然可以使用，只是某些設定被忽略了，例如某個動畫或語氣。有空可以照說明修正。

重新載入後，如果原本選的角色不見了（例如資料夾被移走），小精靈會暫時改用清單裡的第一個角色，但你的設定不會被改掉；角色放回後再按一次「重新載入」，就會換回原本的角色。

想自己做一個角色，請看[小精靈角色開發指南](../sprite-dev-guide.md)。
