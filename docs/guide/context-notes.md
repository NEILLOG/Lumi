# 研究本

> 討論一個問題時，讓 Lumi 把重點整理成一份會自動更新的文件，記下目標、決定、放棄的選項與還沒解決的問題。

## 研究本是什麼？

研究本是跟著一則對話一起產生的文件。你和 Lumi 一邊聊、一邊討論一個問題，每一輪對話結束後，Lumi 會把重點整理進研究本。一則對話只會有一本研究本。

研究本除了上方的「目標」，內容分成七個區段：

- **問題拆解**：把大問題切成幾個小問題。
- **已決定**：已經定下來的事，附上你當時說的原話（預設收起）。
- **待決問題**：還沒有答案的問題。
- **觀點與選項**：各種做法，以及它們的優缺點。
- **否決的選項**：放棄的做法，以及放棄的理由。
- **目前的解與待驗證**：目前認為比較好的做法，以及還需要確認的地方。
- **旁支**：討論中順帶冒出來、暫時不處理的事。

研究本沒有「完成」的狀態，要不要算達成目標由你自己判斷。

## 怎麼開始一本研究本？

有兩種方式：

1. 在工作台上方的工具列按「研究本」，會出現「開一本研究本」對話框：
   1. 在「目標」填一兩句話，最多 200 字。
   2. 在「從哪裡開始」選一個：
      - 「從目前的對話整理」：Lumi 會先讀過這則對話的訊息，整理出第一版。對話還沒有內容時，這個選項不能選。
      - 「從空白開始」：只有目標，之後的對話才開始整理。
   3. 按「開始」。對話框下方會說明這次整理使用的模型，費用算在這則對話裡。
2. 聊了幾輪之後，如果 Lumi 覺得適合整理，會在回答上方出現詢問卡片「要不要為這個問題開一本研究本？」，卡片上已經有建議的目標。按「開研究本」會進入同一個對話框，目標已經填好；按「不用」，這則對話就不再詢問。

要注意的限制：

- Lumi 還在回應時不能開始，「研究本」按鈕會停用，滑鼠停上去會顯示「等這一輪回應結束再開始」。
- 這則對話已經有研究本時，按「研究本」會直接打開它。
- 小精靈模式與排程紀錄沒有研究本。

## 研究本視窗有什麼？

研究本會在獨立的視窗裡打開，和工作台分開。

- **目標**：視窗最上面。按「修改目標」可以改寫，按「儲存」套用、按「取消」放棄。之後的對話會以新的目標為準。
- **預覽與編輯**：工具列左邊的「預覽」「編輯」可以切換。
- **狀態文字**：顯示目前是第幾版、什麼時候更新，或正在整理、等你編輯完再整理、自動整理已關閉。
- **剛更新**：這一版比上一版新增或改過的段落，會有淺色底與左側的色條，並標示「剛更新」。只有最新一版是 Lumi 整理出來的時候才會出現。
- **原話**：「已決定」裡的段落附有你當時說的原話，預設收起。按「原話」展開，按「收起原話」收回。
- **旁支**：預設收合，標題會顯示有幾則。
- **目標可能要調整**：聊的內容明顯離開目標時，視窗上方會出現這個提示。按「修改目標」可以改，按「不用」就關掉。

### 怎麼編輯研究本？

1. 按工具列的「編輯」，切到純文字編輯，可以直接修改任何一段。
2. 七個區段的標題請保留，Lumi 整理時靠它們找到段落。
3. 可以直接在編輯框貼上圖片，圖片會存進研究本的資料夾，切回預覽就看得到。
4. 編輯中 Lumi 不會整理，狀態會顯示「有新的對話內容，等你編輯完再整理」。切回預覽、按「完成」，或關閉視窗時，才會存檔並讓 Lumi 接著整理新的對話。
5. 不想要這次的修改，按「放棄修改」。

研究本最多 20,000 字。超過時「完成」會停用，並顯示目前的字數。研究本很長的時候（約 16,000 字以上），Lumi 會提醒你可以關閉自動整理，見下面的「自動整理與費用」。

## 你寫的內容不會被改

Lumi 整理時會保護你寫的內容：

- **你寫的或改過的段落會自動受保護**，畫面上有鎖頭和「你寫的」。Lumi 會看到它們，但不會改動，之後整理時會原樣保留。
- **Lumi 記下的決定不會自動鎖住**。要鎖住，請在那一段右邊按「這一段的操作」，選「確認這個決定」。之後你在對話裡改變主意，Lumi 不會改掉已確認的決定，而是把不一致的地方記到「待決問題」。
- **標成已決定**：把任何一段搬到「已決定」，並且鎖住。
- **取消保護**：解除鎖住，之後 Lumi 又可以修改這一段。

如果 Lumi 整理時把受保護的段落移動或刪掉了，程式會把它放回原來的區段，視窗會顯示「有 N 段你寫的內容被移動或刪除，已經放回去。」

## 自動整理與費用

- 每輪對話結束後，Lumi 會用目前使用的模型多做一次整理，把新的內容寫進研究本。這次呼叫的費用算在這則對話裡，見[用量、費用與預算](usage-cost.md)。
- 研究本視窗工具列的「自動整理」開關預設是開的。關掉後，Lumi 不會再自動整理；需要時按「更多」裡的「現在整理一次」。
- 沒有新的對話內容時，不會整理，也不會產生新版本。

## 版本歷史與退回

- 每次整理、你的編輯、修改目標、按「標成已決定」或「確認這個決定」，都會存成一版。
- 按工具列的「版本歷史」可以逐版查看。每一版會註明來源（「開始」「書記」「你」「外部修改」「退回」）和原因。
- 選一版，左邊會顯示它和前一版的差異：新增的段落、刪除的段落，以及修改的字。
- 選定一版後按「退回到第 N 版」，確認後會存成新的一版。退回不會刪掉任何一版，之後還可以再退回來。
- 按「回到研究本」可以回到內容畫面。

## 並排

- 研究本視窗工具列的「並排」，會把工作台放在螢幕左半、研究本視窗放在右半，兩個視窗都會先還原成一般大小。
- 排好之後，兩個視窗各自獨立，可以分開移動或縮放，不會黏在一起。
- 螢幕太窄時「並排」會停用，滑鼠停上去會顯示「螢幕太窄，無法並排」。
- 研究本視窗會跟著工作台走：工作台切到另一則對話，視窗就換成那則對話的研究本；那則對話沒有研究本時，視窗會關閉。切到小精靈模式或關閉工作台，視窗也會關閉。
- 視窗的位置與大小會記住，下次打開時回到原來的地方。

## 匯出與資料夾

研究本視窗工具列的「更多」選單有兩個功能：

- **匯出成 zip**：把研究本（`note.md` 與圖片）打包成 zip，存到你選的位置。
- **打開研究本所在的資料夾**：用檔案總管（Windows）或 Finder（macOS）打開資料夾。

資料夾裡面有 `note.md` 和 `images` 資料夾。`note.md` 是一般的 Markdown 檔，其他 Markdown 編輯器（例如 VS Code、Obsidian）也打得開，圖片也看得到。

你可以在其他程式改 `note.md`。存檔後，回到 Lumi 的研究本視窗時，Lumi 會把改動存成一版「外部修改」，改過的內容同樣受保護。

資料夾的位置可以到 設定 › 資料與隱私 查看，見[資料與隱私](privacy.md)。

## 刪除對話會怎樣？

刪除一則對話時，它的研究本（包括版本歷史與資料夾）會一起刪除，確認視窗會提醒你。要保留的話，請先打開研究本，用「更多」裡的「匯出成 zip」存一份。

## 研究本、筆記與長期記憶有什麼不同？

- **研究本**：跟著一則對話走，記這個問題討論到哪裡了。Lumi 在這則對話裡會參考研究本的目標和已決定的事。
- **[筆記](memory.md)**：每天一個檔案，你請 Lumi 記下的一件事就會追加到當天的筆記，不跟著對話走。
- **[長期記憶](memory.md)**：Lumi 記住關於你的長期事實，例如偏好與工作背景，每則訊息都會帶上。研究本和長期記憶互不寫入。

## 常見問題

### 為什麼這一輪沒有更新研究本？

常見的原因有這幾種：

- **這一輪沒有新的內容**，例如只回了「好」或「了解」。這時不會產生新版本，也不會標示。
- **你正在編輯**。狀態會顯示「有新的對話內容，等你編輯完再整理」，按「完成」或切回預覽後才會整理。
- **自動整理已關閉**。狀態會顯示「自動整理已關閉」，按「現在整理一次」可以手動整理。
- **沒有可用的模型**。狀態會顯示「還沒有可用的模型，無法整理。」，到 設定 › AI 連線 設定好模型之後再試。
- **整理失敗或結果不完整**。Lumi 會保留上一版，不會套用這次的結果，狀態會顯示「這次整理失敗，研究本沒有改變。」或「這次整理的結果不完整，沒有套用，研究本沒有改變。」。按「再整理一次」可以重試。

### 為什麼 AI 沒有再問我要不要開研究本？

- 每則對話最多詢問一次。按過「不用」之後，這則對話就不會再問。
- 閒聊、單次的問答，或請 Lumi 寫程式、修改文件時，Lumi 不會詢問。
- 比較早開始的對話沒有這個功能。Lumi 的工具清單是在每則對話開始時決定的，所以舊的對話不會出現詢問卡片，但你可以自己按工具列的「研究本」。
- 小精靈模式與排程紀錄不會詢問。
