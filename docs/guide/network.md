# 網路與 Proxy

> 如果你在公司網路裡連不上：Proxy 與 PAC 設定、測試連線，以及 Lumi 怎麼讀網頁（沒有網路搜尋）。

## 什麼時候需要改網路設定？

多數人不用改，預設的「跟隨系統設定」就能用。如果你在公司網路裡，AI 連線的「測試連線」失敗，或 Lumi 讀不到網頁，常見原因是這台電腦要先經過 Proxy（代理伺服器）才能上網。這時請公司的網路管理者提供 Proxy 的資訊，再到設定 › 網路填寫。

這些設定套用到 Lumi 所有的連線：AI 模型、語音、遠端 MCP 伺服器與網路工具。電腦自己（localhost）的位址一律不經過 Proxy，所以本機的 Ollama 不受影響。設定頁下半部的「瀏覽器」是另一組設定，見[讓 Lumi 操作瀏覽器](browser.md)。

## 連線方式要選哪一種？

「連線方式」有四種：

- **跟隨系統設定**（預設）：用作業系統裡的 Proxy 設定。公司網路通常選這個。
- **使用 PAC 網址**：PAC 是網路管理者提供的一個小檔案，決定每個網站該走哪個 Proxy。填完整的網址，可以是 http、https 或 `file://` 開頭，例如 `http://wpad.example.com/proxy.pac`。
- **手動指定 Proxy**：在「Proxy 位址」填主機與連接埠，例如 `proxy.example.com:8080`。連接埠一定要寫，前面可以加 `http://`、`socks5://` 或 `socks4://`，不寫就是 http。帳號與密碼不能寫在位址裡，要用下面的「Proxy 驗證」。這個模式多一個「不經過 Proxy 的位址」，一行一個，例如 `*.example.com`、`10.*` 或 `10.0.0.5`。
- **不使用 Proxy**：全部直接連線。

PAC 檔下載或執行失敗時，Lumi 會改成直接連線，所以請存檔前先按「測試連線」，確認有照你預期的路徑走。

## Proxy 需要帳號密碼怎麼辦？

選了前三種連線方式後，會出現「Proxy 驗證」：

- **不需要**。
- **使用目前登入的帳號（Windows 網域）**：預設值。Proxy 用公司網域（AD）帳號驗證時，Windows 選這個。
- **帳號與密碼**：自己輸入。帳號可以寫成「網域\帳號」，例如 `CORP\amy`。Mac 若用登入帳號驗證不過，改選這個。

密碼只存在這台裝置。存好後只顯示「已設定」，要改按「更換」。

## 「自動使用 Windows 登入的網站」是什麼？

有些內部網站要求 Windows 登入。列在這裡的網站（一行一個，例如 `*.corp.example.com`），Lumi 的網路工具連過去時，會用你目前登入的 Windows 帳號自動驗證。這項只套用在網路工具，不影響 AI 連線，也只有網站要求 Windows 整合驗證時才會用。

## 逾時要設多久？

「網路工具的逾時（秒）」是網路工具單次請求最多等的秒數，可以填 5 到 120，預設 30。網站很慢時可以調高。

## 怎麼測試與儲存？

1. 選好連線方式，填完需要的欄位。
2. 在「測試網址」填一個你要連的網址，預設是 `https://example.com/`。想確認 AI 服務連得上，可以改填它的網址。
3. 按「測試連線」。用的是畫面上的設定，不必先儲存，最多等 15 秒。成功會寫出經過哪個 Proxy 或直接連線；失敗會顯示「連線失敗」和原因。
4. 按「儲存」。之後的連線就用新設定。

「還原」會把改到一半的內容改回已儲存的值。欄位有錯時，「儲存」旁邊會寫原因。AI 連線本身的測試在設定 › AI 連線，見[AI 連線與模型](connections.md)。

## Lumi 能怎麼讀網路？

Lumi 有一組網路工具，在設定 › 工具的「網路」群組。開關與確認方式見[工具與權限確認](tools.md)。

| 工具 | 能做什麼 | 權限等級 | 小精靈 |
|---|---|---|---|
| 讀取網頁 | 讀網址的內容轉成文字：網頁、純文字、JSON，以及 PDF、Word、Excel、PowerPoint 文件。不會執行網頁的 JavaScript，內容很長時分段讀 | 網路 | 可用 |
| 列出網頁連結 | 列出網頁上的連結，找下一頁要讀哪裡 | 網路 | 可用 |
| 讀取 RSS | 列出 RSS 或 Atom 的最新項目 | 網路 | 可用 |
| 呼叫網路 API | 只讀取（GET、HEAD） | 網路 | 不可用 |
| 送出資料到網路 API | 送出資料（POST、PUT、PATCH、DELETE），每次都要你確認 | 破壞性 | 不可用 |
| 下載檔案 | 存到你加入的資料夾，不覆蓋既有檔案，單檔最多 200 MB，不下載執行檔與安裝檔 | 寫入 | 不可用 |
| 爬取網站 | 讀同一個網站的幾頁，存成 Markdown 檔；預設 10 頁，最多 20 頁，往下最多 3 層連結。會遵守網站的 robots.txt，需要登入或 JavaScript 的網站會改用 Lumi 的瀏覽器 | 寫入 | 不可用 |
| 網路診斷 | 檢查連到某個網址的 Proxy、DNS、連線與憑證，不讀網頁內容。連不到網站時可以請 Lumi 用它 | 網路 | 可用 |

## Lumi 有網路搜尋嗎？

沒有。Lumi 不提供網路搜尋，請直接給 Lumi 網址。想查某個網站的資料，把網址貼進對話就可以。如果硬要讀搜尋引擎的搜尋頁，確認卡片會警告：可能被擋或要求驗證、結果不穩定、查詢內容會傳給那個網站，而且不能選「本次對話都允許」。

## 沒出現過的網站會怎樣？

Lumi 只會自動連到對話中出現過的網站，其他網站會先問你：

- 你在訊息裡寫過的網址，整個網站都算出現過。
- 你加入的檔案內容與工具結果裡的網址，只有那個完整網址算。
- Lumi 自己寫出來的網址不算。

不算出現過的網站，確認卡片一定會顯示「這個網站沒有在對話中出現過」的警告，即使工具設定成不用確認也一樣。請確認是你要連的網站再允許；允許之後，這則對話裡同一個網站就不會再問。排程執行時，沒出現過的網站也一律要你確認，見[提醒、計時器與排程](reminders.md)。
