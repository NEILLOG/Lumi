# 語音輸入

> 設定 Whisper 語音服務的端點與 Token，用麥克風說話輸入；工作台與小精靈都能用，也說明按鈕不能按的原因。

語音輸入是按下麥克風，把你說的話轉成文字，放進輸入框或直接送出。Lumi 本身**不內建語音辨識**，錄音會送到你自己設定的 Whisper 語音辨識服務去轉成文字。沒有設定服務之前，麥克風按鈕是灰的。

## 開始前要準備什麼？

1. **一個語音辨識服務的網址（端點）**，也就是畫面上「服務端點」要填的位址。可以是你自己架的，也可以是別人（例如公司的資訊部門）提供給你的。
2. **這個服務給你的 Token**。Token 是一組專屬密碼，讓服務知道是你在使用。
3. **一支能收音的麥克風**，並且允許 Lumi 使用它（見下方「麥克風權限」）。

Lumi 會用固定的方式呼叫服務，給自己架服務的人參考：用 POST 送出 multipart 表單，錄音檔是 WAV（16 kHz、單聲道、16-bit），另外附上 `mode`（固定 `normal`）、`language`、`return_format`（固定 `json`）、`source_pgm`（固定 `Lumi`）、`file_name`，以及目前對話的代號 `session_id`；Token 放在 `Authorization: Bearer` 標頭。回應要是帶有 `text` 欄位的 JSON，或純文字。Lumi 不會送 `model` 欄位。

## 怎麼設定語音服務？

1. 點右上角的齒輪打開設定視窗，進入設定 › 語音。設定首頁的「待處理」如果寫著「語音辨識尚未設定」，也可以從那裡進來。
2. 在「服務端點」填入完整網址，例如 `https://你的主機/路徑`。規則：
   - 一定要以 `https://` 開頭。只有 `localhost`、`127.0.0.1` 這種本機位址才可以用 `http://`。
   - 不能包含帳號密碼，也不能有 `?` 或 `#` 後面的部分。
   - 填錯時欄位下方會直接說明原因，在修正前無法儲存。
3. 「語言」選一個：「留空（服務判斷）」「中文 zh」「英文 en」「日文 ja」，也可以自己輸入其他語言代碼。預設是 `zh`。留空時由服務判斷語言。
4. 「逾時秒數」是等服務回應的上限，超過就放棄。預設 120，可以填 5 到 600 的整數；長的錄音或比較慢的服務可以調高。
5. 在「Token」貼上服務給你的 Token，想檢查有沒有貼對可以按「顯示」。畫面寫著 Token 需具備 `WHISPER_API` 權限；這是服務端的權限名稱，你的服務如果沒有這項設定，照服務提供者的說明取得可用的 Token 即可。
6. 按「測試連線」。Lumi 會送出半秒鐘的靜音給服務，服務有正常回應就顯示「連線成功，服務接受了這組端點與 Token。」。測試用的是你正在編輯、還沒儲存的設定，所以可以先測再儲存；沒有輸入 Token 且沒存過 Token 時，會要你先輸入。失敗時會寫「連線失敗」和原因，處理方式見[常見問題與錯誤訊息](troubleshooting.md)。
7. 按「儲存」，成功會顯示「已儲存。」。想放棄修改按「還原」。

Token 儲存後，畫面只會顯示「已設定 · 結尾 xxxx」，不會再顯示完整內容；要換新的按「更換」，要刪掉按「清除」（清除後語音輸入會停用，直到重新輸入）。Token 跟端點的主機綁在一起：改成別的主機時，舊 Token 不會送過去，畫面會要你重新輸入，避免 Token 被送到不該去的地方。Token 只存在這台電腦，加密方式與 AI 連線的金鑰相同。

如果服務使用的是自己簽發的憑證（例如公司內部簽發），電腦不信任它時會連線失敗。畫面上的做法是把簽發的單位（內部 CA）的憑證安裝到作業系統，詳細請洽服務提供者。如果你在公司網路裡需要經過 Proxy，語音和 AI 連線走同一套設定，請看[網路與 Proxy](network.md)。

## 在工作台怎麼用語音輸入？

1. 點輸入框下方的「語音輸入」。輸入框會換成收音列，顯示已錄的時間（例如 `00:12 / 01:30`）和音量波形。
2. 說話。收音列有三個按鈕：
   - 「取消」：丟掉這段錄音。按鍵盤的 Esc 也一樣。
   - 「停止並編輯」：停止錄音並轉成文字，文字放進輸入框，你可以修改後再自己送出。
   - 「停止並送出」：停止錄音，轉寫完成後直接送出。
3. 停止後會顯示「正在辨識語音…」，並標出錄音長度。這時可以按「取消」放棄。
4. 轉寫完成，文字會出現在輸入框，前面標著「語音轉寫」。你一改動或清空文字，這個標示就消失。

細節：

- **最長 90 秒**。錄到 90 秒會自動停止，照「停止並編輯」處理。要講更長的話，分成幾段錄。
- **太短或沒聲音會被忽略**：不到半秒會顯示「錄音時間太短，已忽略」；整段幾乎沒聲音會提示確認麥克風權限；服務回覆沒有文字會顯示「沒有聽到內容」。
- **「停止並送出」不一定會直接送**：只有在同一則對話、Lumi 沒在回答、輸入框是空的時候才會直接送出。否則文字會接在輸入框原有的文字後面（換一行），並提示你確認後再送出。
- **錄音中如果 Lumi 開始回應，或你切換到別的對話，錄音會自動取消。** 錄音進行中也不能加入檔案或資料夾。
- **失敗時錄音會保留**：轉寫失敗會顯示「語音轉寫失敗」和原因。按「重試轉寫」會重新送出同一段錄音，按「放棄」就丟掉。處理前，麥克風按鈕會先停用。原因見[常見問題與錯誤訊息](troubleshooting.md)。

錄音只暫存在記憶體裡，沒有存成檔案。

## 在小精靈模式怎麼用？

小精靈的輸入列也有麥克風鈕，用法和工作台一樣：點麥克風開始收音，輸入列換成收音列，顯示時間和音量。按鈕是圖示，把滑鼠停在上面會顯示名稱：叉叉是「取消」，方塊是「停止並編輯」，向上箭頭是「停止並送出」。

- 轉寫完成後，文字放進小精靈的輸入框，前面標著「語音」。「停止並送出」符合條件（同一則對話、沒在回答、輸入框是空的、小精靈顯示中）時會直接送出，並先以小字引用轉寫的內容。
- 失敗時，氣泡會顯示「語音轉寫失敗：原因」，可以重試或放棄。
- 小精靈被暫時隱藏時，如果正在收音，錄音會被丟掉，不會在背景繼續錄。
- 工作台和小精靈**共用同一個錄音功能**，一次只能有一邊在錄音或轉寫；另一邊的麥克風會是灰的，提示「另一個視窗正在語音輸入」。

## 麥克風權限

系統沒有允許 Lumi 使用麥克風時，Lumi 會提示沒有收到聲音或找不到麥克風。

- **Windows**：打開系統設定的「隱私權與安全性」，進入「麥克風」，允許桌面應用程式存取麥克風。
- **macOS**：打開「系統設定」，進入「隱私權與安全性」，點「麥克風」，允許 Lumi。

Windows 上如果麥克風正被別的程式使用，要先關掉那個程式。更多狀況見[常見問題與錯誤訊息](troubleshooting.md)。

## 麥克風按鈕是灰的怎麼辦？

把滑鼠停在灰色的麥克風上會顯示原因，例如還沒設定服務、Token 沒填、Lumi 正在回應中，或上一段錄音還沒處理。每一種的處理方式見[常見問題與錯誤訊息](troubleshooting.md#語音輸入按鈕灰掉了)。

## 語音會送到哪裡？

錄音和目前對話的代號（`session_id`）只會送到你在「服務端點」填的服務，不會送到 AI 連線的供應商。轉寫出來的文字和你打字輸入的一樣，送出後才會成為對話內容，傳給 AI 模型。
