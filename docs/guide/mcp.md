# 連接外部工具（MCP）

> MCP 是什麼、需不需要、怎麼新增伺服器，以及有什麼風險。

## MCP 是什麼？我需要它嗎？

MCP（Model Context Protocol）是一種讓 AI 助理接上外部工具的做法。你在電腦上執行一個 MCP 伺服器（可以是本機的一個程式，也可以是網路上的服務），它會把自己提供的功能列成「工具」，Lumi 就能像使用內建工具一樣呼叫它們。

一般使用者通常不需要它。Lumi 已經內建讀檔案、寫檔案、讀網頁、設提醒、操作瀏覽器等工具，見[工具與權限確認](tools.md)。只有在你要用的功能不在內建清單裡，而且已經有人提供對應的 MCP 伺服器時，才需要設定。不確定的話，可以先略過這一頁。

## 新增伺服器前要準備什麼？

- **本機指令**：伺服器的啟動指令，例如 `npx`、`uvx`，或程式的完整路徑；還有它需要的參數。
- **遠端 HTTP**：伺服器提供的網址，必須以 https 開頭（只有 `localhost` 這類本機位址可以用 http）；如果伺服器要求驗證，還需要它指定的標頭與值。

網址裡不能含帳號與密碼，驗證資訊請放在標頭。

## 怎麼新增一個伺服器？

1. 點右上角的齒輪打開設定視窗，點左邊的「工具」，再切到上方的「MCP 伺服器」分頁。
2. 點「新增伺服器」。
3. 在「名稱」填一個你看得懂的名字，例如 `檔案工具`。
4. 在「連線方式」選「本機指令」或「遠端 HTTP」。
5. 選「本機指令」時，填「指令」；「參數」一行填一個。需要環境變數時，按「新增環境變數」，填名稱與值。
6. 選「遠端 HTTP」時，填「URL」；需要標頭時，按「新增標頭」，填標頭名稱與值。
7. 需要調整時，展開「進階」。「代號」會出現在這個伺服器所有工具的名稱裡，通常不用改；「逾時秒數」是工具呼叫的時間上限，可填 5 到 600，預設 60。
8. 按「測試連線」。成功會顯示「連線成功，找到 N 個工具。」，並列出前 10 個工具名稱；失敗會顯示「連線失敗」與原因。
9. 按「儲存」。

測試連線不是儲存的必要步驟，但只要有欄位標示錯誤，就不能儲存。新伺服器預設是啟用的，但不會在小精靈使用。Lumi 啟動時會連上每個已啟用的伺服器。

## 怎麼從 JSON 一次匯入？

如果伺服器的說明已經提供 JSON 設定，可以直接匯入，不用逐一填寫：

1. 在「MCP 伺服器」分頁的清單上方，點「從 JSON 匯入」。
2. 把設定貼進文字框。Claude Desktop、Claude Code、VS Code 的格式都可以，只要內容含有 `mcpServers` 或 `servers`。
3. 按「解析」。下方會列出每一筆的名稱、連線方式與目標；無法匯入的項目會寫出原因。
4. 確認後按「匯入 N 筆」。有錯誤的項目不會匯入，其他項目仍會匯入。

名稱重複時會自動改名，例如「名稱 (2)」，預覽上會標示。匯入的伺服器預設啟用，不在小精靈使用。舊版 SSE 格式不支援，預覽會寫出原因，請改用伺服器的 Streamable HTTP 網址。

## 金鑰和標頭的值存在哪裡？

- 環境變數與標頭的**值**只存在這台裝置，不放在一般的設定內容裡，和 AI 連線的金鑰一樣。
- 儲存後，畫面不會再顯示完整的值，只會寫「已設定」。要換值按「更換」，要刪掉按「移除」。
- 名稱（例如 `API_KEY`）不是祕密，仍會顯示在畫面上。
- 刪除伺服器時，它的環境變數與標頭的值會一併刪除。

## 外部工具的權限怎麼決定？

- **預設是「寫入」等級**，每次使用都會先在對話裡問你，可以選「允許一次」、「本次對話都允許」或「拒絕」。
- **權限等級由你決定。** 在設定 › 工具的「工具清單」找到這個伺服器的群組，在工具的「權限等級」選單選擇「唯讀」、「寫入」、「網路」或「破壞性」。
- 改成「唯讀」時會先確認。確認後，Lumi 使用這個工具就不會先問你，所以只有在你確定它不會修改任何東西時才這樣設定。
- 改成「破壞性」後，每次都會問，不能選「本次對話都允許」，也不能設為「永遠允許」。
- **伺服器的標示只是建議。** 卡片上的「伺服器標示：唯讀」或「伺服器標示：會刪除或覆蓋」，是伺服器自己的說法，Lumi 不會因此改變權限，要以你的判斷為準。
- **允許一個外部工具，不會連帶允許其他外部工具**，即使它們來自同一個伺服器。「本次對話都允許」記的也是單一工具。
- 不想每次確認時，可以在同一列的「確認方式」改成「永遠允許」。

## 怎麼管理已經新增的伺服器？

- **狀態**：清單上每個伺服器會顯示「已連線 · N 個工具」、「連線中…」、「連線失敗」或「已停用」。連線失敗時，詳細區會寫出原因，原因與處理方式見[常見問題與錯誤訊息](troubleshooting.md)。
- **停用**：取消勾選「啟用」並儲存，伺服器會停止連線，它的工具不會再送給模型。
- **離線**：伺服器沒有連線時，工具清單仍會列出上次取得的工具，並寫明「伺服器未連線，顯示上次取得的工具。」
- **也在小精靈使用**：預設關閉，這些工具只能在工作台使用。打開後，小精靈也能使用。
- **刪除**：按「刪除」並確認，伺服器與它的環境變數、標頭一起刪除。

## 工具說明會佔多少用量？

每個工具的名稱、說明與參數格式，都會在每次送出請求時一起送給模型，佔用的是「用量單位」（tokens）。清單上每個伺服器下方會寫出「工具說明約 N tokens」。啟用的伺服器越多，每次請求送出的內容就越多；用不到的伺服器可以先停用。

## 使用時要注意什麼？

- **本機指令會用你的帳號權限，在這台電腦上執行**，所以只加入你信任的伺服器。
- **外部工具的結果會送到你目前使用的模型供應商。** 這些結果來自伺服器，不一定可靠，允許前請看清楚卡片上要做什麼。
- 不確定某個伺服器是否可信時，先不要加入。
