## 新功能

- **技能**：把一套做事的方法教給 Lumi，例如照公司格式寫週報。之後你提出相符的要求，Lumi 會先讀這套步驟再照著做；對話裡會出現「使用技能」的卡片，讓你知道它用了哪一個。這個功能只在**新對話**有效。
- **三種方式加入技能**：在工作台做完一件事後說「把剛才的流程存成技能」（每次都會先請你確認）；到「設定 › 技能」自己寫；或匯入別人分享的技能資料夾、zip 檔。匯入的技能附帶的腳本不會被執行，也不會被複製。
- **輸入框多了「技能」按鈕**：想指定用哪個技能時，點開選一個，Lumi 一定會照它做。

詳細說明見使用教學的[技能](https://github.com/NEILLOG/Lumi/blob/main/docs/guide/skills.md)。
