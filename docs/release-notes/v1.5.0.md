## 新功能

- **研究本**：討論一個問題時，按工作台上方工具列的「研究本」，Lumi 會在每一輪對話後把重點整理成一份文件，記下目標、已決定的事、放棄的選項和還沒解決的問題。你可以自己編輯、鎖住重要的決定，也可以退回之前的版本。聊了幾輪之後，Lumi 也可能主動問你要不要開一本。整理會另外使用模型，費用算在這則對話裡。詳細說明見使用教學的[研究本](https://github.com/NEILLOG/Lumi/blob/main/docs/guide/context-notes.md)。
- **支線**：遇到看不懂的名詞時，在回答下方按「開支線」，或選取一段文字後按「問這段」，就能另開一段對話去問，不會打亂原本的討論。弄懂之後按「帶回主線」，Lumi 會整理重點，等你在主線送出下一則訊息時一起帶進去。詳細說明見使用教學的[支線](https://github.com/NEILLOG/Lumi/blob/main/docs/guide/branches.md)。
- **回到最新訊息**：往上捲動看舊內容時，對話區下方會出現「回到最新訊息」按鈕，按一下就回到最底下。
- **中鍵拖曳捲動**（Windows）：在對話區按住滑鼠中鍵拖曳，可以快速上下捲動，寬的表格和程式碼區塊也能左右捲。
- **顯示回答用的模型**：到「設定 › 進階」開啟「在每則回答下方顯示使用的模型」，每則回答下方會顯示是哪個模型回的，以前的回答也看得到。
- **等待回應的動畫**：等 Lumi 回應時，三個圓點會依序跳動，不再是靜止的「…」。

## 修正

- 「資料與隱私」頁的說明改成和實際行為一致：送出檔案時排除的範圍、記錄檔記了什麼、金鑰存放的位置、用量紀錄、語音與網路工具會送出哪些資料；資料位置新增「產生的圖片」。
- 語音相關的說明與錯誤訊息不再假設你在特定公司使用。
- 修正幾處說錯設定位置或名稱的提示文字，例如模型沒開「使用工具」時的說明、工具使用次數上限的說法。

## 升級前請注意

- 這一版會升級資料庫。升級後如果改回 1.4.0 或更舊的版本，會打不開原本的資料。
