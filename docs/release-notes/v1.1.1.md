## 新功能

- **新對話也知道你最近在做什麼**：同一件事分成好幾則對話做時，不用每次重新交代。開新對話時，Lumi 會參考最近 3 則對話（7 天內）的標題、你的要求、做過的動作和回覆片段。這些內容會隨第一則訊息送到目前使用的模型供應商；不想要的話，可以到「設定 › 記憶」關閉。
- **小精靈可以待在工作台**：到「設定 › 小精靈」打開「在工作台顯示小精靈」，它就會在新對話的歡迎區和工具列旁陪你。預設是關閉的，不影響任何功能。

## 改善

- 工作台工具列的模型選單移到左邊。

## 修正

- MCP 工具回傳的圖片（例如畫面截圖）現在會交給 Lumi 看，也會直接顯示在回覆裡，可以點開放大。模型不支援看圖時，Lumi 會改用文字重新傳送，不會卡在錯誤。
