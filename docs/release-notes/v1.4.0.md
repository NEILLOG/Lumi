## 新功能

- **Outlook 信件與行事曆**（Windows，需要傳統版 Outlook）：Lumi 可以幫你找信、讀信、存附件、查行程、新增自己的行程，也能替你寫好信件草稿、回覆、轉寄與會議邀請，在 Outlook 打開讓你檢查後再自己按「傳送」。這個功能**預設關閉**，到「設定 › 工具」的「Outlook」群組開啟，開啟後在**新對話**才會用到。
  - **寄給自己**：請 Lumi 把整理好的內容寄到你自己的信箱，不需要每次確認。
  - **確認後寄出**：要直接寄給別人時，每次都會先跳出確認卡，列出收件人、主旨與內容，你按「允許」才會寄出。
  - 信件內容會和你貼在對話裡的文字一樣，送給你選用的 AI 模型。**公司規定信件不能送到外部服務時，請不要開啟。**
  - 詳細說明見使用教學的[Outlook 信件與行事曆](https://github.com/NEILLOG/Lumi/blob/main/docs/guide/outlook.md)。
- **設定 › 工具**：這台電腦不能用的工具會停用並說明原因；整組開關的警告同一段只需要確認一次。
- **按停止後有回饋**：回應還沒有內容就按停止時，會顯示「你已停止這次回應」和「重試」。

## 修正

- 中文輸入法選字時，輸入游標不會跟著移動的問題（內部元件升級到 Avalonia 12）。
- Windows 的標題列不再疊上視窗標題與全螢幕按鈕。
- 對話區、程式碼區塊與表格的捲軸不再自動隱藏，更容易點到；程式碼區塊最後一行不再被蓋住。
- 「啟用太多工具」的提示不再一直出現：門檻改依模型能處理的長度計算。
- 新增 AI 連線時，Base URL 放在名稱下面，不用再展開「進階」。
- 服務沒有提供模型清單時，測試連線顯示「連得上」，不再顯示失敗。
