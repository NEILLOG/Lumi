## 新功能

- **排程讓 Lumi 自動做事**：跟 Lumi 說「每天早上 9 點幫我整理……」，時間到它會自己跑，結果放在歷史對話的「排程」分頁，也可以接著聊。建立前會先請你確認它可以做哪些事。
- **塔羅牌**：可以請 Lumi 抽牌，支援單張、三張（過去／現在／未來）和凱爾特十字。解讀僅供娛樂與自我反思，不是預言。
- **牌和圖片直接出現在回覆裡**：抽到的牌、產生的圖片會跟著 Lumi 的回答一起顯示，不用再展開工具卡片。
- **在 Lumi 裡放大看圖**：點圖片可以直接縮放、拖曳，不必另開看圖程式；點一張塔羅牌可以看大圖和牌義。
- **用量與費用**：設定裡多了「用量與費用」頁，可以看每月花費、設定預算提醒、匯出 CSV；對話中也看得到這次用了多少。

## 改善

- 圖片產生中會顯示進度和經過的秒數。
- 加入對話的大圖會先縮小再送出，比較省用量。
- 工具連續失敗時會提早停下來，不會一直重試、浪費用量。
