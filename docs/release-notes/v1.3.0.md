## 新功能

- **執行指令**：開啟後，Lumi 可以在工作台替你執行 PowerShell、cmd 或 bash 指令，例如在專案資料夾裡 `npm install`、查磁碟空間，再根據結果繼續回答。每次執行前都會先請你確認，看不懂的指令請按「拒絕」。這個功能**預設關閉**，只建議熟悉指令的人到「設定 › 工具」開啟，開啟後在**新對話**才會用到。詳細說明見使用教學的[執行指令](https://github.com/NEILLOG/Lumi/blob/main/docs/guide/commands.md)。
- **對話自動取標題**：第一次送出後，Lumi 會幫對話取一個好認的標題，歷史紀錄裡比較容易找。訊息很短時維持原文。
- **流程圖直接顯示成圖片**：Lumi 畫的流程圖、時序圖會直接畫出來，點一下可以放大；右上角可以切換看原始碼。
- **複製時保留格式**：按回覆下方的「複製」，貼到 Word、Outlook、Teams 會保留標題、粗體、清單、表格和連結；貼到記事本則是原文。選取一段文字再複製，格式也會一起帶走。
- **長訊息自動收合**：你自己貼的長訊息只先顯示前幾行，按「顯示全部」展開。

## 修正

- 設定 › 用量與費用的金額顯示成 0，儲存預算時 Lumi 直接關掉的問題。現在讀不到用量時會說「讀不到這個月的用量」，不會顯示 0，也不會讓程式結束。
- 小精靈清除對話內容後，歷史紀錄的標題不再留著上一次的內容。
